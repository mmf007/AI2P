# Security Policy

**Please do not report security vulnerabilities through public issues.** Use
**Security → Report a vulnerability** (private vulnerability reporting) of this repository.

Only the latest release is supported. The full policy — supported versions, how to report,
response times and the threat model (including what a CLI agent can access) — is available
in five languages:

* [English](doc/en/man/SECURITY.md)
* [Русский](doc/ru/man/SECURITY.md)
* [Español](doc/es/man/SECURITY.md)
* [Português](doc/pt/man/SECURITY.md)
* [中文](doc/zh-cn/man/SECURITY.md)
