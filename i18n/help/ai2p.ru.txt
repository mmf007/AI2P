AI2P — ai2p: КЛИЕНТ КОМАНДНОЙ СТРОКИ ИИ-АГЕНТА

Тонкая обёртка над «AI2P.Server cli …». Лежит В КАТАЛОГЕ УСТАНОВКИ рядом с
программой и запускает её же с подкомандой cli — второго исполняемого файла в
выкладке нет.

Реквизиты берутся из переменных окружения, которые процессу агента задаёт сам AI2P:
AI2P_URL (адрес сервера по петле) и AI2P_JOB_TOKEN (токен задания, живёт только пока
задание идёт). Вне задания клиент не работает намеренно.

ИСПОЛЬЗОВАНИЕ
  ai2p help                     список команд и доступных заданию действий
  ai2p --help                   то же самое
  ai2p parent                   родительское задание
  ai2p siblings                 задания-соседи
  ai2p children T-22            подзадачи задачи
  ai2p task T-15                задание по коду
  ai2p chat T-15                чат задания
  ai2p find «часть заголовка»   поиск заданий
  ai2p message --text "…"       написать человеку в чат задачи
  ai2p subtask --title "…" --description-file d.md   создать подзадачу
  ai2p status T-15 --status pending --restart        вернуть чужую задачу в работу
  ai2p experience --text "…" --scope project         записать опыт
  ai2p file <ссылка>            получить файл задания на диск

Список действий, реально разрешённых этому заданию, печатает «ai2p help»: ответ
приходит с сервера и учитывает правила безопасности задачи. Язык ответов — язык
КОМАНДЫ задания, а не этого скрипта.
