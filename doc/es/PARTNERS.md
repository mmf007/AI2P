# Colaboración, inversiones y contribución al proyecto (AI2P)

¡Bienvenido! El proyecto `mmf007/AI2P` sienta una base jurídica y comercial sólida desde el primer
día de desarrollo. Estamos abiertos a colaborar tanto con desarrolladores independientes como con
inversores de capital riesgo.

---

## Situación jurídica y licencias

[![Licencia: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](../../LICENSE)
[![CLA assistant](https://cla-assistant.io/readme/badge/mmf007/AI2P)](https://cla-assistant.io)

1. **Licencia básica:** el código fuente del núcleo se distribuye bajo la licencia permisiva
   **Apache 2.0**. Da la máxima libertad a los usuarios y es totalmente segura para el uso
   comercial.
2. **Protección de la propiedad intelectual (CLA):** para conservar la posibilidad de
   comercialización y proteger los derechos de los inversores, todos los desarrolladores externos
   están obligados a firmar un *Contributor License Agreement* mediante el servicio automático
   **CLA Assistant** al enviar su primer Pull Request. Esto garantiza que el proyecto pueda
   escalarse o relicenciarse en el futuro sin obstáculos.

---

## 💡 Modelo de negocio (Open Core)

Pensamos desarrollar el proyecto según un esquema híbrido:
* **Core (la base abierta):** siempre seguirá siendo gratuita y disponible para la comunidad y para
  los usuarios habituales bajo la licencia Apache 2.0.
* **Enterprise (la capa corporativa):** los módulos adicionales (seguridad avanzada, registros de
  auditoría, integraciones, soporte empresarial) se suministrarán bajo una licencia comercial
  cerrada y de pago.
