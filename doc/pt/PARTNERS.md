# Parceria, investimentos e contribuição para o projeto (AI2P)

Bem-vindo! O projeto `mmf007/AI2P` constrói uma base jurídica e comercial sólida desde o primeiro dia
de desenvolvimento. Estamos abertos à cooperação tanto com desenvolvedores independentes quanto com
investidores de capital de risco.

---

## Situação jurídica e licenciamento

[![Licença: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](../../LICENSE)
[![CLA assistant](https://cla-assistant.io/readme/badge/mmf007/AI2P)](https://cla-assistant.io)

1. **Licença básica:** o código-fonte do núcleo é distribuído sob a licença permissiva
   **Apache 2.0**. Ela dá a máxima liberdade aos usuários e é totalmente segura para uso comercial.
2. **Proteção da propriedade intelectual (CLA):** para preservar a possibilidade de comercialização e
   proteger os direitos dos investidores, todos os desenvolvedores externos são obrigados a assinar
   um *Contributor License Agreement* pelo serviço automático **CLA Assistant** ao enviar o primeiro
   Pull Request. Isso garante que o projeto possa ser escalado ou relicenciado no futuro sem
   obstáculos.

---

## 💡 Modelo de negócio (Open Core)

Pretendemos desenvolver o projeto por um esquema híbrido:
* **Core (a base aberta):** permanece sempre gratuita e disponível para a comunidade e para os
  usuários comuns sob a licença Apache 2.0.
* **Enterprise (a camada corporativa):** os módulos adicionais (segurança avançada, logs de
  auditoria, integrações, suporte empresarial) serão fornecidos sob licença comercial fechada e paga.
