# Grok-4.7

**部署位置:** 云端（xAI API，OpenAI 兼容）
**接入方式:** `provider: openai-compatible`，`baseUrl: https://api.x.ai/v1`，
模型 `grok-4.7`
**密钥引用:** `xai.apiKey`

xAI 于 2026-09-21 发布该模型；它通过任务 T-347-S0（2026-09-23 的厂商巡检）进入
AI2P 模型目录。标识符 `x-ai/grok-4.7`、上下文长度、价格与模态均已通过对公开目录
OpenRouter 的请求核对。

延续 **Grok-4.6** 系列：上下文 500 000 令牌，回复最多 64 000 令牌，每百万令牌 1,60 $ 和
4,80 $。技能评分 89–93。

接受的输入：文本与 Markdown、源代码、图像、PDF。

## 如何获取密钥

1. 在 [xAI 控制台](https://console.x.ai/)注册。
2. 建一个团队（team）并充值余额 —— 没有余额，请求会被拒绝。
3. 打开 **API Keys → Create API Key**，起个名字并给它聊天模型的权限。
4. 复制那个值 —— 它**只显示一次**。密钥以 `xai-` 开头。
5. 在 AI2P 中：**设置 → 名录 → AI 模型 → Grok-4.7 →「设置 API 密钥」**。

密钥属于组织：用组织的密钥加密，并复制到组织的所有服务器上（技术规格第 10 章）。

## 硬件要求

没有任何要求：计算在提供商一侧。需要能访问 `api.x.ai` 的互联网连接。

## 常见错误

* **账单高于估算** —— 任务很可能越过了 xAI 提高资费的请求长度门槛（4.7 版未公布该门槛）。
  请让聊天记录短一些，或者把材料放进文件。
* **模型「不知道」最近发生的事** —— xAI 未公布 4.7 版的知识边界；请把最新信息直接写进任务。
* **403 /「no credits」** —— xAI 团队的余额没有充值。
