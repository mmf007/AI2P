# Claude-Sonnet-5_cli

**部署位置:** 云端，但接入方式**不是 API，而是 CLI**
**接入方式:** `provider: anthropic`，`transport: cli`，命令
`claude --permission-mode acceptEdits`，模型 `claude-sonnet-5`
**密钥引用:** 空 — **不需要 API 密钥**

与 Claude-Sonnet-5 是同一个模型，但通过 headless 模式的 **Claude Code CLI** 启动。付费方式
不是按令牌，而是**按订阅**，因此在 AI2P 的计费中这类作业的费用为零。它的定位是与项目文件
打交道的大工作量任务 — 当您不想为令牌付费的时候。

## 不需要 API 密钥

授权靠的是 CLI 的会话，而不是密钥。因此配置档中的 `secretRef` 为空，这个模型也没有
「设置 API 密钥」按钮。

代替密钥需要做的是：

1. **安装 Claude Code** — [官方说明](https://docs.claude.com/en/docs/claude-code/overview)。
   检查方法：在控制台里 `claude --version` 应该能打印出点什么。
2. **用您的订阅登录**：`claude login`。会话保存在操作系统的用户配置文件中。
3. 确认 `claude` 在**运行 AI2P 的那个用户的 PATH** 中可用。如果 AI2P 是以另一个账户作为
   服务运行的，登录也要在那个账户下完成。
4. 如果可执行文件不在 PATH 中 — 请在模型配置档的 `cliCommand` 字段中写上完整路径。

## 与 API 变体有什么不同

| | 通过 API | 通过 CLI |
|---|---|---|
| 付费 | 按令牌 | 按订阅 |
| 计费中的费用 | 会计算 | 0 |
| 工具 | AI2P 的工具 | **CLI 自带的工具** |
| 工作目录 | 无所谓 | **项目文件夹** |
| 向人提问 | 标准方式 | 靠回复中的 `AI2P_QUESTION` 标记 |
| 创建子任务 | 用 `create_task` 工具 | 靠 `AI2P_SUBTASK` 标记 |

差异的详细分析见 Claude-Fable-5_cli 的文档；Sonnet 这边的机制完全一样。

## 限制与价格

| | |
|---|---|
| 上下文 | 1 000 000 令牌 |
| 最大响应 | 128 000 令牌 |
| 费用 | 0（由订阅支付） |

**订阅限额 AI2P 能够识别并等待重置**（v1.63 的改动）：看到 CLI 返回 429 的拒绝后，系统会
取得重置时间，并把任务转为「等待中」而不是「出错停止」，重置之后**继续同一个会话**
（`--resume`），而不是从头开始作业。请在 AI 执行者那里填好「每个窗口的令牌限额」和
「限额窗口，小时」（Claude 订阅的窗口是 5 小时），这样系统就能提前预警。

## 许可证

| | |
|---|---|
| 对生成结果的条款 | **结果归您**：Anthropic 把它对 Outputs 的权利让与您（Consumer Terms，第 4 条） |
| 商业使用 | 允许；「仅限个人非商业用途」的说法针对的是试用访问，而不是付费订阅 |
| 必须做到 | 遵守 Usage Policy；记住按消费者条款，在您到账户设置中拒绝之前，您的材料会被用于训练模型 |
| 条款文本 | <https://www.anthropic.com/legal/consumer-terms> （2025-10-08 版） |
| 生成费用 | 按订阅，而非按令牌 — 在 AI2P 的计费中这类作业费用为 0 |

这里重要的是别把两份协议弄混。Claude 订阅适用的是**消费者**条款；API 密钥适用的是**商业**
条款（<https://www.anthropic.com/legal/commercial-terms>），其中根本不存在用您的数据训练
这回事。

实际的推论：如果作业处理的是保密协议下的他人代码或数据，那么按 API 密钥的变体比订阅变体
更安全 — 或者请在 Claude 账户设置中拒绝参与训练。

条款已按其文本于 2026-08-27 核对。

## 硬件要求

没有特别要求：由提供商计算。需要安装好的 Claude Code、互联网连接以及项目目录中的空间 —
代理是直接和文件打交道的。

## 常见问题

* **「找不到 claude」** — CLI 没有安装，或者不在 AI2P 用户的 PATH 中。
* **无声拒绝或要求登录** — 会话是在操作系统的另一个账户下建立的。
* **代理看不到任务的文件** — 项目没有设置目录（「项目文件夹」）。
