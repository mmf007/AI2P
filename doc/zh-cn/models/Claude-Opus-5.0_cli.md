# Claude-Opus-5.0_cli

**部署位置:** 云端，接入方式**通过 CLI**
**接入方式:** `transport: cli`，命令 `claude --permission-mode acceptEdits`，
模型 `claude-opus-5`
**密钥引用:** 空 — **不需要 API 密钥**

Claude-Opus-5.0，通过 headless 模式的 **Claude Code CLI** 启动。付费方式是订阅，在 AI2P
的计费中这类作业的费用为零。

## 不需要 API 密钥

授权靠的是 CLI 的会话。设置方式与 Claude-Fable-5_cli 完全一样：

1. 安装 [Claude Code](https://docs.claude.com/en/docs/claude-code/overview)；
2. **在运行 AI2P 的那个操作系统用户下**执行 `claude login`；
3. 确认 `claude` 在该用户的 PATH 中可用（否则请在模型配置档的 `cliCommand` 中写上完整
   路径）。

这项设置对两个 CLI 模型是共用的：做一次，两个都开通了。

## 订阅限额（v1.62 的改动）

CLI 不会报告订阅限额的余量：`claude --help` 里没有，作业的 JSON 输出里也没有，而 `/usage`
只在交互式会话中有效。因此消耗量由 AI2P 自己统计 — 按滑动窗口内各作业的令牌数。为了让它
生效，请在 AI 执行者那里（执行者 → 执行者表单）填好两个字段：

* **每个窗口的令牌限额** — 您愿意在一个窗口内花掉多少令牌；这个值要根据您的订阅通过实践
  摸索；
* **限额窗口，小时** — Claude 订阅的窗口是 **5 小时**。

字段留空 — 一切照旧：不统计余量，也没有预警。填好了 — AI2P 在启动任务前会检查余量，如果
几乎没有了，就把启动推迟到窗口释放的时刻，并在任务聊天中留言（也可以改为把任务拆成子任务，
或者强制启动）。推迟的启动时刻保存在任务里：计算机可以关机，开机后任务会自行启动。

**如果限额还是在工作中途到了**（v1.62 的改动），CLI 会返回一条简短消息，形如
`5-hour limit reached ∙ resets 4:10pm (Europe/Moscow)`。AI2P 认得它，从中取出重置时间，
并且**不把它算作任务的错误**：作业以一份说明性的产物收尾，执行者被标记为「忙碌至」，而任务
转为**「等待中」** — 卡片头部会看到「等待至 <时间>」的标签，聊天中会出现一条消息。时间到了，
任务会自行启动 — **作为新作业、从头开始**（代理已经写进项目文件的一切都原样保留）。不需要
守在计算机旁：可以关机。如果消息中没有重置时间 — 那就等一小时。

## 响应超时（v1.63 的改动）

CLI 代理自己维持它的循环，工作期间是**沉默的** — AI2P 只能看到进程结束的那一刻。要等它多久，
由执行者表单中的 **「响应超时，分钟」** 字段决定：

* **空** — 30 分钟（系统默认值，就是 1.63 之前写死在代码里的那个）；
* **数字** — 就等这么多分钟；
* **0** — 无限等待；只有「停止」按钮才能中断作业。

超时到了 — 作业以**错误**结束，并提示在哪里把这个值调大，任务转为「出错停止」。此时执行者
**不会被标记为忙碌**：在 1.63 之前，代理的沉默会被当作订阅限额耗尽，执行者会因此有一小时
退出工作，尽管限额可能才用掉三分之一。真正的限额 AI2P 仍然是按 CLI 自己的消息识别的
（见上一节）。

## 关于 CLI 接入需要记住什么

* 代理使用的是 **CLI 自带的工具**，AI2P 的工具不会提供给它；
* 进程的工作目录是**项目文件夹**，所以它必须被设置好；
* AI2P 的安全规则不适用于代理在该目录内的动作；
* 向人提问是靠回复中的 `AI2P_QUESTION` 标记传递的，对话的继续用的是同一个 CLI 会话
  （`--resume`）；
* 子任务由代理用回复中的 `AI2P_SUBTASK` 标记创建 — 代替它没有的 `create_task` 工具
  （见 Claude-Fable-5_cli）；
* 在层级中移动任务（更换父任务、移到根）代理可以用 `AI2P_MOVE_TASK` 标记 — 代替
  `move_task` 工具；
* 其他作业的文本（描述、结果和整个聊天）代理用 `AI2P_GET_TASK` 标记请求 — 代替它同样
  没有的 `get_task_by_code` / `get_task_by_url` / `get_task_chat` 工具。

关于 API 与 CLI 差异的更多内容，见 Claude-Fable-5_cli 的文档。
