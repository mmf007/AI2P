# Claude-Fable-5

**部署位置:** 云端（Anthropic 提供商 API）
**接入方式:** `provider: anthropic`，模型 `claude-fable-5`
**密钥引用:** `anthropic.apiKey`

已接入的模型中最强的一个：代码、文本、需求分析和规划。用它来承担流程中的关键任务和需求
分析是合理的，而日常琐事交给更便宜的模型 — 「价格 ↔ 质量」的比重在项目中设置。

## 如何获取密钥

1. 在 [Anthropic Console](https://console.anthropic.com/) 注册。
2. 充值余额：**Plan & Billing → Add credits**。余额不为正时密钥仍然能创建，但请求会以
   资金不足的错误被拒绝。
3. 打开 **Settings → API keys → Create Key**，给密钥起个好认的名字（例如 `AI2P-工作用`）。
4. 复制那个值 — 它**只显示一次**。密钥以 `sk-ant-` 开头。
5. 在 AI2P 中：**设置 → 名录 → AI 模型 → Claude-Fable-5 → 「设置 API 密钥」**。值填在
   密码型字段里，之后在任何地方都不会再显示。

密钥属于**组织**：它用组织的密钥加密，并复制到组织的所有服务器上，因此不需要在每台服务器
上都输入一遍。详情见技术规格第 10 章。

密钥一旦设置好，模型就会启用。没有密钥，云端模型不可能处于已启用状态。

## 限制与价格

| | |
|---|---|
| 上下文 | 1 000 000 令牌 |
| 最大响应 | 128 000 令牌 |
| 输入价格 | 10,00 $ / 100 万令牌 |
| 输出价格 | 50,00 $ / 100 万令牌 |

每个作业的费用都按这些数字计算并进入计费（技术规格 6.2-bis 节）。最新价格请见
[Anthropic Pricing](https://www.anthropic.com/pricing) 页面 — 如果价格变了，请修改模型
能力声明中的 `cost`。

**模型标识符未经真实调用验证。** 在下达第一个作业之前，请用向提供商 API 发送
`GET /models` 的方式核对它：Anthropic 的检查点名称会变动，而错误的 id 会在执行者那里
直接给出 404。

| | |
|---|---|
| 对生成结果的条款 | **结果归您**：Anthropic 把它对 Outputs 的全部权利让与您（Commercial Terms，B 节） |
| 商业使用 | 允许 — 这是面向组织的条款，消费者条款不适用于 API |
| 必须做到 | 遵守 Usage Policy；不得基于该服务构建竞品、用它训练竞争模型、转售访问权 |

模型权重是封闭的，不会分发给任何人 — 这里没有什么可授权的，因此条款针对的是**生成结果**，
而不是权重。

按同一份条款，Anthropic **不会用送进 API 的内容训练模型**（「Anthropic may not train
models on Customer Content from Services」）。同一模型的订阅版变体（带 `_cli` 后缀的记录）
条款**不同** — 那里适用的是消费者条款，在您到账户设置中拒绝之前，都会用您的材料进行训练。

条款已按其文本于 2026-08-27 核对；提供商有权修改 — 商业发布前请再打开链接看一次。

## 硬件要求

没有任何要求：计算在提供商一侧进行。只需要能访问 `api.anthropic.com` 的互联网连接。

## 常见问题

* **「找不到 API 密钥」** — 密钥没有输入，或者这台服务器还没有拿到组织密钥（它在服务器
  接入组织被确认时下发）。
* **提供商返回 401** — 密钥被吊销，或者没有复制完整。
* **「37529 tokens exceeds context」** — 任务描述过于庞大；请减少输入，或者提高配置档中的
  `params.maxTokens`。
* **安全分类器拒绝** — 配置档中设有兜底 `params.fallbacks: ["claude-opus-5"]`：请求会自动
  用另一个模型重试。

## 无需密钥的替代方案

同一家族还有一个通过 CLI 接入的变体 — **Claude-Fable-5_cli**：它通过 Claude Code 订阅
工作，不需要 API 密钥。请看它的文档。
