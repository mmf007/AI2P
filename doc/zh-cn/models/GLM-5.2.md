**部署位置:** 云端（Z.ai / Zhipu，OpenAI 兼容）
**接入方式:** `provider: openai-compatible`，`baseUrl: https://api.z.ai/api/paas/v4`，
模型 `glm-5.2`
**密钥引用:** `zai.apiKey`

**Kimi-K3 之后开放模型里代码最好的一个** —— `code-write` 评分 91（满分 100），
而价格还便宜了三分之二：每百万令牌 1,19 $ 和 3,74 $。上下文
1 048 576 令牌。定位很明显：Opus 和 GPT-5.6-Sol 用起来太贵的大批量代码工作。

写文本不如写代码（评分 83–86），输入只有文本和源码，模型不接受图片。

## 如何获取密钥

1. 在 [z.ai](https://z.ai/) 上注册（智谱的国际站点）。
2. 在计费板块充值余额 —— 没有余额，请求会被拒绝。
3. 打开[密钥列表](https://z.ai/manage-apikey/apikey-list) → **Create API key**，
   起个名字。
4. 复制那个值 —— 它**只显示一次**。
5. 在 AI2P 中：**设置 → 名录 → AI 模型 → GLM-5.2 →「设置 API 密钥」**。

密钥属于组织：用组织的密钥加密，并复制到组织的所有服务器上（技术规格第 10 章）。

## 硬件要求

没有任何要求：计算在提供商一侧。需要能访问 `api.z.ai` 的互联网连接。

## 常见错误

* **任何请求都返回 404** —— `baseUrl` 里的路径被截短或加长了（需要 `/api/paas/v4`）。
* **401「invalid api key」** —— 密钥是在中国站点（`bigmodel.cn`）创建的，
  而地址用的是国际站。
* **模型拒绝接受图片** —— 输入只有文本；多模态任务请用 MiniMax-M3 或 Gemini。
