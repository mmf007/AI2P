# Chatterbox-TTS

**部署位置:** 云端 —— 网关 [fal.ai](https://fal.ai/models)
**接入方式:** `provider: fal-ai`，`baseUrl: https://queue.fal.run`，模型 `fal-ai/chatterbox/text-to-speech`
**密钥引用:** `fal.apiKey`
**功能:** 文本 + 语音样本 → 该音色的语音，技能 `audio-speech` 88

这是首批接受**参考音频**的目录条目（T-249-S0 的机制）。角色的固定嗓音在这里不靠 LoRA 适配器，
而靠**样本**：3–30 秒的录音进入请求的 `audio_url` 字段，模型据此复制音色（zero-shot 克隆）。
任务文本进入 `text` 字段。

微调字段为 `exaggeration`（表现力，0–1，模板中为 0.25）、`temperature`（0.7）和 `cfg`（0.5）。该端点的文本长度上限为 5000 个字符。

## 如何使用

1. 在项目中建立一个**参考录音**类型的对象（项目卡片的「对象」标签页），文件字段填写相对于项目
   文件夹的 `.wav` 或 `.mp3` 路径；通常作为角色的子对象。
2. 在任务描述中用 `@obj:OBJ-N` 引用它，或者用文字写出文件名（「语音样本 refs/vera.wav」）。
3. 把执行者指向这条目录条目 —— 按端点模式，语音样本**不是必填**（该字段有默认音色），但 AI2P 的请求模板里放了 `{audio}` 占位符——因此没有录音的作业会带着清晰的提示停下，而不会用别人的音色发往网关。

## 如何获取密钥

1. 在 [fal.ai](https://fal.ai/) 注册账号（可用 GitHub 或 Google 登录）。
2. 在 [Billing](https://fal.ai/dashboard/billing) 充值：网关按预付费工作，余额为零时请求会被拒绝。
3. 打开 [API Keys](https://fal.ai/dashboard/keys)，点击 **Add key**。
4. 复制该值 —— 它只显示**一次**。
5. 在 AI2P 中：**设置 → 模型 → Chatterbox-TTS → 「API 密钥」**。

所有 fal.ai 条目共用**同一把**密钥（引用 `fal.apiKey`）：填写一次即可启用网关的全部云端多媒体模型。
密钥属于组织 —— 用组织密钥加密并复制到组织的所有服务器（技术规格第 10 章）。没有密钥，目录条目
不能处于启用状态，也无法指派给执行者。

## 硬件要求

没有要求：计算由提供方完成。需要能访问 `queue.fal.run`（提交作业与轮询状态）和网关的文件存储
（`*.fal.media`）—— AI2P 从那里把成品文件下载到任务产物中。语音样本以 `data:` 地址**放在请求体内**
发送，网关没有单独的文件上传。

## 作业是怎样下达的

多媒体模型的提示词就是**整个任务描述**：标题、验收标准和项目经验都到不了它那里。

* 描述中的 `@obj:OBJ-3` 引用在**每次**运行时都会展开成项目对象的逐字档案 —— 修改档案对下一次作业
  立即生效；
* 指向**参考录音**类型对象的引用会**强制**把文件传给模型；
* 「把结果放到文件 `audio/line-1.wav`」这一行还会把成品文件放进项目文件夹；任务产物中始终有它；
* 这个模型无法接收起始画面（`refImage.kind: none`）—— 如果描述里写了图片文件，AI2P 会在作业控制台
  用一行文字说明；
* 请求字段在模型档案的 `request` 小节中修改；取值请参考模型页面上的端点模式，未知取值会被网关以
  HTTP 422 拒绝。

## LoRA

这里**无法**训练和挂接适配器，目录中也如实写明：`"lora": { "supported": false, "reason": "provider" }`。
权重在提供方一侧，它不接受您的适配器文件。凡是引用了带 LoRA 适配器对象的作业都到不了生成阶段：
AI2P 会立即拒绝，并在聊天中推荐能胜任的执行者（T-14-S1）。这里的固定嗓音由**参考录音**保持，而且
比训练便宜：十秒钟的克隆不比适配器差，却分文不花。

## 常见错误

* **「未传入参考录音」** —— 任务描述里既没有指向「参考录音」对象的 `@obj:` 引用，也没有音频文件名；
  请求模板中有 `{audio}` 占位符，作业会在发送前停止。
* **「该模型不接受录音」** —— 执行者指向了别的目录条目；只有 T-251-S0 报告中列出的条目才声明
  `refAudio` 小节。
* **网关返回 HTTP 422** —— 请求模板里出现了端点没有的字段，或取值不在模式的枚举范围内。
* **「找不到 API 密钥」** —— 没有在任何 fal.ai 条目中填写密钥；在其中任意一条填写一次即可。
* **网关返回 HTTP 401 / 403** —— 密钥无效或已被吊销。
* **HTTP 429** —— 提供方限制了请求频率，请稍后重试作业。
