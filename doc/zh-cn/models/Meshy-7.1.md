与目录中其他媒体记录一样，通过 fal.ai 网关接入：文本 → 可直接用于游戏的网格，四边面拓扑与 PBR 贴图（技能 `3d-generate` 89）。

**Meshy-7** 之后的新版本（那条记录仍然有效：目前只有一个更新版本，而停用门槛是三个）。

## 如何获取密钥

1. 在 [fal.ai](https://fal.ai/) 上建立账户（通过 GitHub 或 Google 登录）。
2. 在 [Billing](https://fal.ai/dashboard/billing) 一节充值：网关是预付费的，
   账户上没钱请求会被拒绝。
3. 打开 [API Keys](https://fal.ai/dashboard/keys) 并点击 **Add key**。
4. 复制那个值 —— 它**只显示一次**。
5. 在 AI2P 中：**设置 → 模型 → Meshy-7.1 →「API 密钥」**。

所有 fal.ai 记录的密钥是**同一个**（引用 `fal.apiKey`）：设置一次，就一并启用了全部
十二个云端媒体模型。密钥属于组织 —— 用组织的密钥加密，并复制到组织的所有服务器上
（技术规格第 10 章）。没有密钥，名录记录不可能处于已启用状态，也无法作为执行者被选中。

## 硬件要求

## 作业是怎样下达的

媒体模型的提示词就是**任务描述的全文**：标题、验收标准和项目经验都到不了它那里。

* 描述中的 `@obj:OBJ-3` 引用在**每次**启动时都会展开成项目对象（角色、场景、风格）
  的逐字档案 —— 修改档案会立刻作用于下一帧；
* 「положить результат в файл `видео/кадр-1.mp4`」这样的一行会把做好的文件另外放进
  项目文件夹一份；在任务产物中它总是存在的（**这类指示只按俄语和英语识别** ——
  单词列表写死在代码里，场景文本可以用任何语言写）；
* 这个模型没有办法接收起始帧 —— 如果描述中指名了图片文件，
  AI2P 会在作业控制台里用一行说明这件事，而不会默不作声；
* 请求的各个字段（时长、分辨率、声音、多边形数）在模型配置档的 `request` 一节中修改；
  取值请从模型页面的端点 schema 中获取，网关会用 HTTP 422 拒绝不认识的取值。

## LoRA

这里**无法**训练和接入适配器，名录中也如实记着：
`"lora": { "supported": false, "reason": "provider" }`。模型权重是封闭的，
提供商不接受您自己的适配器文件。凡是指名引用了带 LoRA 适配器的对象的作业，
都到不了生成阶段：AI2P 会立即拒绝，并在聊天中推荐一个会做这件事的执行者（T-14-S1）。
这里保持形象稳定，靠的是固定的 `params.seed` 和同一段物件描述文本。

## 常见错误

* **网格对引擎来说太重** —— 请调小请求模板中的 `target_polycount`。
* **需要给现成模型重新贴图或绑定** —— 那是提供商另外的端点，目前还没有自己的名录记录。
* **「未找到 API 密钥」** —— 任何一条 fal.ai 记录都没有设置密钥；在其中任意一条里
  设置一次即可。
* **网关返回 HTTP 401 / 403** —— 密钥无效或已被吊销。
* **HTTP 429** —— 提供商限制了请求频率，请稍后重试作业。
