# YandexGPT-5.1-Pro

**部署位置:** 云端（Yandex Cloud，俄罗斯；OpenAI 兼容）
**接入方式:** `provider: openai-compatible`，
`baseUrl: https://llm.api.cloud.yandex.net/v1`，模型
`gpt://<folder-id>/yandexgpt/latest`
**密钥引用:** `yandex.apiKey`

俄语文本很强：`text-write` 86、`text-translate` 86、`text-edit` 85。代码是弱项
（60–64），编程不该选这个模型。按名录的标准，上下文也偏小：32 000 个令牌。

## 「模型」字段里要填上您自己的地址

Yandex Cloud 等的不是一个短标识符，而是**完整的资源名**：

```
gpt://<folder-id>/yandexgpt/latest
```

**目录标识符（folder ID）每个用户都不一样**，所以名录里留的是占位符 ——
这条记录「开箱即用」是跑不起来的。请打开
**设置 → 名录 → AI 模型 → YandexGPT-5.1-Pro →「连接配置档」**，
把 `<folder-id>` 换成您自己的（形如 `b1g...`，在 Yandex Cloud 控制台的目录地址里
能看到）。`latest` 也可以换成某个具体的模型版本。

## 如何获取密钥

1. 在 [Yandex Cloud 控制台](https://console.yandex.cloud/)里建一个目录，
   并接入付费账户。
2. 创建一个**服务账户**，给它在该目录上的 `ai.languageModels.user` 角色。
3. 为服务账户创建 **API 密钥**：**服务账户 → 您的账户 →
   创建新密钥 → 创建 API 密钥**。
4. 复制密文部分 —— 它**只显示一次**。
5. 复制**目录标识符**，把它填进配置档的「模型」字段（见上）。
6. 在 AI2P 里：**设置 → 名录 → AI 模型 → YandexGPT-5.1-Pro →
   「设置 API 密钥」**。

## 硬件要求

没有：计算在供应商那边。需要能访问 `llm.api.cloud.yandex.net` 的网络。

## 常见错误

* **400 /「model not found」** —— 「模型」字段里还留着占位符
  `<folder-id>`。
* **403「permission denied」** —— 服务账户没有拿到目标目录上的
  `ai.languageModels.user` 角色。
* **长描述会让作业中断** —— 32 000 个令牌的上下文不够用；请把材料放到文件里，
  在描述中只给出引用。
