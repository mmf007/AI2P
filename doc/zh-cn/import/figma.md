# 从 Figma 导入设计——连接说明

导入会把 **Figma 设计中的一个区域** 变成 AI2P 任务：屏幕（以及可选的设计元素）以
**图片** 形式导入，任务描述中每张图片下方按从上到下的顺序列出该画框的 **全部文字**——按钮、
标题、输入框等。这样“实现这个屏幕”的任务既有外观，也有原样的文字。需要一个 Figma
个人访问令牌和导入目录中的一条记录。

## 1. 获取令牌

**没有令牌时 Figma API 完全不响应——即使是无需登录即可在浏览器中打开的公开文件。**
令牌始终是必需的。

1. 登录 Figma，打开 <https://www.figma.com/settings> → **Security** 选项卡。
2. 在 **Personal access tokens** 中点击 **Generate new token**。
3. 名称任意，例如 `AI2P import`；有效期自定。
4. 权限（scopes）：**File content → Read only**，其他都不需要。
5. 点击 **Generate token** 并复制字符串。它以 `figd_` 开头，**只显示一次**。

令牌可读取您的账号能看到的一切——请像密码一样保管。

## 2. 在导入目录中创建导入源

**设置 → “目录”选项卡 → “导入目录” → “添加”：**

| 字段 | 填写内容 |
| --- | --- |
| 导入源名称 | 任意，例如 `Figma 设计` |
| 类型 | Figma |
| 启用 | 暂不可用——第 3 步后会自动启用 |

Figma 导入源没有其他字段：只能 **通过链接** 导入设计区域。点击 **“保存”**。

## 3. 输入令牌

用 **“编辑”** 打开已保存的导入源，点击 **“设置令牌”**，粘贴第 1 步的字符串。Figma 没有
API 密钥：只有一个机密、一个按钮。若值不以 `figd_` 开头，表单会给出提示。输入令牌后，
导入源 **会自动启用**。

**“检查连接”** 会向 Figma 询问“我是谁”，并用文字回答：令牌是否被接受、属于哪个账号。

令牌以 **加密** 形式保存在组织数据库中，并同步到组织的所有服务器。

## 4. 导入设计区域

1. 在 Figma 中 **选中区域**——一个屏幕、包含多个屏幕的分区或一个页面——并复制选区链接：
   右键 → **Copy link to selection**（或 `Ctrl+L`）。链接中会出现 `node-id=…` 参数，
   这就是区域。
2. 在 AI2P 中选择项目，在任务列表中点击 **“按 URL 导入任务”**。
3. 粘贴链接，例如
   `https://www.figma.com/design/rqN1QJdU35Q18H5mpUmlFd/Home-Planner?node-id=54965-55076`。
   窗口中出现两个选项：
   * **“设计元素作为单独图片”**——关闭：仅主要屏幕；打开：每个屏幕元素也作为单独图片，
     并附各自的文字；
   * **“导入整个文件”**——仅当链接中 **没有** `node-id` 时显示。不勾选则拒绝这样的链接：
     整个文件可能非常大。
4. 点击 **“导入”**：图片下载到项目中，内容填入新任务表单。补全表单并保存。

### 什么是屏幕、什么是元素

* **指向画框（frame）的链接** 即 **一个屏幕**：其嵌套画框是屏幕的组成部分。
* **指向页面、分区或组的链接**——其中的顶层画框成为屏幕（分区和组会被穿透）。
* **元素**（若打开）——组件及其实例（不再深入）以及嵌套的画框和组。同一组件、文字相同的
  重复实例只取一次。非常小的图层（小于 8 px）会被跳过。
* 隐藏图层不导入。

### 描述的样子

来源说明（文件、区域、链接），然后每个屏幕一节：`## 1. 屏幕名称`、图片、**“文字：”**
列表。若包含元素——“屏幕……的元素”小节，每个元素同样排列。图片为 2× PNG（非常大的画框为 1×）。

## 5. AI 智能体

智能体可用 `import_task_from_url` 工具执行同一动作（动作代号 `AI2P.Tasks.ImportFromUrl`），
CLI 智能体使用 `ai2p import <链接> --elements true|false [--wholeFile]`。**这两个选项都是要
问用户的问题**：智能体未提供时不会导入，并会被要求询问用户。没有 `node-id` 的链接只有在
用户明确同意后才会导入。

## 6. 从 Figma 更新任务

导入的任务带有 **“导入链接”**，其中记住了区域以及“元素”（`ai2p-elements=1`）或“整个文件”
（`ai2p-whole=1`）的选择。**“更新” → “从导入源”** 会以相同方式重新读取设计：标题和
**整个描述都会被重写**，并附新的图片。验收标准、执行者、状态和关联不变。旧图片保留在
项目的 uploads/ 中。

## 故障排查

| 消息 | 原因与处理 |
| --- | --- |
| “未按引用……找到 Figma 令牌” | 未输入令牌：见第 3 步。 |
| “Figma 不接受该令牌……”（`Invalid token`，403） | 令牌错误、已撤销或已过期。重新生成（第 1 步）。 |
| “Figma 拒绝访问……”（403） | 令牌缺少 **File content: Read** 权限，或文件对令牌所属账号不可见。 |
| “Figma 未找到文件或节点……”（404） | 链接错误：文件键或 `node-id`。 |
| “链接中没有节点（node-id）……” | 复制选区链接，或打开“导入整个文件”。 |
| 屏幕下方显示“没有图片……” | Figma 未渲染该节点（为空或过大）。文字仍然保留。 |
| “已达到单次导入的图片上限（300）……” | 元素太多：用单独的链接分别导入设计的各部分。 |
| “Figma 导入源没有批量导入” | 请使用“按 URL 导入任务”。 |

请求详情见应用日志（`logs/*.jsonl`，`FigmaImporter` 记录）；令牌的值从不写入日志，只记录
长度和前缀。

## 限制

* 每次导入最多 **300 张图片**。
* 设计评论不会转入任务聊天。
* 没有批量导入——仅支持链接。
