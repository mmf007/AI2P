# 快速开始

从下载到获得 AI 智能体第一个成果的最短路径。没有多余内容：设置、模板、团队和集群都留到以后 —
它们各有自己的章节。

需要 10–15 分钟，其中大部分时间用于下载。

---

## 第 1 步。下载

安装包在这里：**${refpackages}**

每个系统有两个文件，在它们之间选择就是选择「是否需要单独的运行时」：

| 文件 | 里面是什么 | 何时选它 |
|---|---|---|
| `AI2P_full_v_1_NN_win64.exe` | 程序**连同运行时** | 常规情况：不需要额外补装任何东西 |
| `AI2P_v_1_NN_win64.exe` | 只有程序 | 如果计算机上已经装有 **ASP.NET Core 8.x** 运行时 |

Linux 和 macOS 上是同样两个文件，只是扩展名为 `.run`（`AI2P_full_v_1_NN_Linux.run`）。
`NN` 是版本号；请取最大的那个。

> 拿不准就选 **`full`**。它体积更大，但除了它自己什么都不需要。

## 第 2 步。安装

### Windows  
运行下载到的文件。安装程序会询问是**为所有用户**安装还是**仅为我**安装 —
程序目录以及它的工作文件放在哪里都取决于此；详见[安装](install.md)一章。试用时选「仅为我」即可：
不需要管理员权限。

### Linux

```sh
chmod +x AI2P_full_v_1_NN_Linux.run
./AI2P_full_v_1_NN_Linux.run
```

安装到 `~/ai/AI2P`。不需要 `root` 权限：服务器以普通用户身份运行。

### macOS

```sh
chmod +x AI2P_full_v_1_NN_macos.run
./AI2P_full_v_1_NN_macos.run
```

安装到 `~/ai/AI2P`。不需要 `root` 权限：服务器以普通用户身份运行。  

## 第 3 步。启动

桌面上的 **AI2P** 快捷方式（或安装目录中的 `AI2P.Server.exe` / `./AI2P.Server`）。
程序会自己打开浏览器访问 `http://localhost:5480/ai2p`。

没有打开 — 请手工输入这个地址。带有错误文字的窗口关得太快 —
请看[「如果程序无法启动」](install.md#5-如果程序无法启动)。

## 第 4 步。走完首次启动向导

第一次启动时 AI2P 不会直接进入界面，而是按步骤引导。一共六步：

| 步骤 | 询问什么 | 值得知道的事 |
|---|---|---|
| **1. 语言** | 界面语言 | 默认给出浏览器的语言；所选语言**立即**对后面所有画面生效 |
| **2. 服务器** | 服务器名称、协议、端口和**三个硬件目录** | 服务器名称就是它**在网络中**的名字；单机安装用 `localhost` 即可，明确填上就行。目录（模型权重、安装包、软件包）可以保持默认 |
| **3. 用户** | 姓名、邮箱、电话、密码 | 复选框**「密码与服务器管理员密码相同」**已勾选 — 请保留：这样服务器设置马上就能用。密码可以留空，但那样就只能从本机登录 |
| **4. 组织** | 名称和地址中的代号 | 代号会进入地址（`/ai2p/<代号>/…`）。复选框**「集群主服务器」**请保持勾选：取消勾选意味着「接入别人的服务器」 |
| **5. 典型用途** | 代码与分析 / 视频 / 图片 / 没有典型用途 | 系统会按回答为您搭好工作台 |
| **6. 第一个项目** | 名称和**文件夹** | 文件夹就是智能体读写文件的地方。没有它就不会把文件工具交给智能体 |

走完最后一步，您已经拥有：一个组织、服务器 `S0`（它同时是指挥服务器）、作为所有者的您、
**三个 AI 执行者 `Jon`、`Bob` 和 `Stiv`**、团队 `<组织>_team` 以及一个指定了文件夹的项目。

> 在全新安装上选「编写程序代码或做分析」会得到三个使用 **Claude 订阅**模型的执行者。
> 全新安装上没有可用于视频和图片的已启用模型 — 向导会如实说明这一点，但团队和项目照样会创建。

## 第 5 步。给系统一个模型

执行者有了，但只有当他们的模型有支付手段时才能干活。
打开**设置**（左侧栏底部的齿轮）→ **「模型」**标签页。

从下面三条路中选**一条**：

**a) Claude 订阅（最快，不需要密钥）。** 列表上方的**「登录 Claude CLI」**按钮。
带 `_cli` 后缀的记录就是这样工作的 — 向导填进去的正是它们。

**b) API 密钥。** 找到需要的模型，点击它那一行的密钥按钮，粘贴供应商的密钥。
记录会自行启用：**没有密钥的云端模型不可能处于启用状态**。

**c) 本地模型。** 模型行中的「安装」按钮会下载权重并装好所需的软件包。
这很慢（若干 GB）并且需要显卡 — 对第一次启动来说不是最快的路。

某条记录能做什么、价格多少、需要什么 — 看它那一行的**「i」**按钮
（以及[模型列表](../models/README.md)）。

## 第 6 步。下达任务

打开**任务**（左侧栏）→ **「添加」**按钮 → **「空任务」**。

请填写：

* **标题** — 简短说明工作内容。
* **描述** — 像写给人看那样：做什么、在哪里做、用什么检验。这就是提示词；
  智能体需要知道的一切都必须写在这里。
* **验收标准** — 怎样才算做完。
* **技能** — 实际需要做的事情（例如 `code-write-cs`、`text-write`）。自动挑选就靠它们。
* **执行者** — 或者从列表中选（`Jon`、`Bob`、`Stiv`），或者点击字段旁的自动挑选按钮：
  **「先 AI，后真人」**。

项目和团队会自动填入 — 就是当前打开的那些。

## 第 7 步。启动并取得结果

任务卡片上有**「启动」**按钮。接下来：

* 状态变为**「进行中」**，旁边可以看到具体是谁在工作；
* 工作过程可以在**「作业历史」**中看到：工具调用、文件读写、令牌消耗；
* 如果智能体缺少什么，它会**在任务聊天中提问** — 任务会进入「暂停」，
  收件箱里出现一个问题。您在聊天中回答，工作就会从原处继续；
* 做完后，智能体把结果作为**任务产物**放好（报告文本、文件、图片），
  任务转入**「待检查」** — 验收工作由您来做。

智能体对文件所做的一切都在项目文件夹里 — 正是您期待它们出现的地方。

## 如果出了问题

| 看到什么 | 为什么 | 怎么办 |
|---|---|---|
| 「启动」按钮毫无反应 | 任务没有执行者 | 指派一个执行者或点击自动挑选 |
| 任务立刻「出错停止」 | 模型没有密钥或者没有登录 | 设置 → 模型：填密钥或者「登录 Claude CLI」 |
| 任务处于「暂停」 | 智能体提了问题，或者执行者用完了限额 | 看看任务聊天和收件箱 |
| 智能体看不到项目文件 | 项目没有指定文件夹 | 项目卡片 → 文件夹字段 |
| 智能体拒绝执行某个动作 | 触发了安全规则 | 设置 → 安全 |
