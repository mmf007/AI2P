# VS Code 插件

该插件让本服务器能够把项目与 VS Code 关联（项目卡片 →「连接 VS Code」）。
它没有给智能体的动作，只负责以下程序：

| 程序 | 用途 | 查找方式 |
|---|---|---|
| Visual Studio Code | 项目所关联的编辑器 | 先查找已安装的副本（PATH 中的 `code` 命令）；未找到时「安装」会把**最新**稳定版以便携压缩包形式下载到软件包目录 |

## 多个 VS Code 副本

若机器上有多个副本，请在插件窗口的「Visual Studio Code」一行指定用于关联项目的那一个
（Windows：`<VS Code 目录>\bin\code.cmd`）。该副本即**内部**副本：项目的副本选择表单会标注「内部」并默认选中它。

## 启用

找到或安装 VS Code 后插件自动启用。手动停用的插件不会自动重新启用。

## 与项目关联

「连接 VS Code」会先检查插件；未连接时启动连接，缺少的程序在后台安装。找不到 VS Code 时无法连接项目。
