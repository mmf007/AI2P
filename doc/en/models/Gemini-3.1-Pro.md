# Gemini-3.1-Pro

> **The record was switched off on 2026-09-11 (task T-216-S0, the vendor sweep).** This
> version has more than three newer versions of the same family (3.5, 3.6, 3.7, 3.8), and its identifier is no longer in the public model catalogue. The record is

> back on with the “active” checkbox: **Settings → Catalogs → AI models**.

**Hosting:** cloud (Google, through an OpenAI-compatible layer)
**Connection:** `provider: openai-compatible`,
`baseUrl: https://generativelanguage.googleapis.com/v1beta/openai`, model `gemini-3.1-pro`
**Key reference:** `google.apiKey`

The working model of the Gemini line: skill scores 86–91 at a price of $2 and $12 per million
tokens — five times cheaper than Gemini-3-Ultra and with a context of
1,048,576 tokens. It is strong at summaries, translation and data analysis.

It accepts text, sources, pictures and PDFs as input, and also **audio and video**
(`audio/*`, `video/*`) — the material of a job may arrive as a recording.

## How to obtain the key

**The key is the very same** as for the other Gemini models: all three records refer to
`google.apiKey`. If it has already been entered, this model will work on its own.

If there is no key yet:

1. Open [Google AI Studio](https://aistudio.google.com/apikey) and sign in with a Google
   account.
2. Press **Create API key**, pick a Google Cloud project.
3. Copy the key (it starts with `AIza`).
4. Link the project's billing — on the free tier long jobs run into a 429.
5. In AI2P: **Settings → Catalogs → AI models → Gemini-3.1-Pro → «Set API key»**.

## Hardware requirements

None: the computation happens on the provider side. Internet access to
`generativelanguage.googleapis.com` is required.

## Common errors

* **404 "model not found"** — the id has changed; check it against the `GET /models` list.
* **429 on a long job** — the project's billing is not linked.
* **An empty answer with the reason `length`** — raise `params.maxTokens` in the profile
  (32000 by default).
