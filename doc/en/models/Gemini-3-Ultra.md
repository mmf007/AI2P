# Gemini-3-Ultra

> **The record was switched off on 2026-09-11 (task T-216-S0, the vendor sweep).** This
> version has more than three newer versions of the same family (3.1, 3.5, 3.6, 3.7,
> 3.8), and its identifier is no longer in the public model catalogue. The record is
> kept in the reference: executors, past jobs and reports point at it. It can be turned
> back on with the “active” checkbox: **Settings → Catalogs → AI models**.

**Hosting:** cloud (Google, through an OpenAI-compatible layer)
**Connection:** `provider: openai-compatible`,
`baseUrl: https://generativelanguage.googleapis.com/v1beta/openai`, model `gemini-3-ultra`
**Key reference:** `google.apiKey`

**The largest context in the reference — 2,000,000 tokens**, twice as much as Claude and GPT.
That is what it is kept for: a job with a huge description, a long correspondence or a whole
pile of attached material goes through in one piece. The skill scores are 90–94, the strong
sides being summaries and data analysis. The price is high: $10 and $30 per million tokens.

It accepts not only text and pictures as input, but also **audio and video** (`audio/*`,
`video/*`), so it suits jobs where the material arrives as a recording.

## How to obtain the key

1. Open [Google AI Studio](https://aistudio.google.com/apikey) and sign in with a Google
   account.
2. Press **Create API key**, pick or create a Google Cloud project.
3. Copy the key (it starts with `AIza`).
4. For the paid tier link the project's billing: the free tier throttles the request rate and
   on long jobs the agent will run into a 429.
5. In AI2P: **Settings → Catalogs → AI models → Gemini-3-Ultra → «Set API key»**.

The key is shared with all the Gemini models of the reference —
Gemini-3.1-Pro and Gemini-3.7-Flash refer to the
same `google.apiKey`.

## Hardware requirements

None: the computation happens on the provider side. Internet access to
`generativelanguage.googleapis.com` is required.

## Common errors

* **404 "model not found"** — the id is wrong; check it against the `GET /models` list.
* **429 on a long job** — the free tier is in effect; link billing.
* **An error on tools** — a quirk of the compatibility layer; try
  Gemini-3.1-Pro or another provider.
