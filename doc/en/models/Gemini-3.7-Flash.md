# Gemini-3.7-Flash

**Hosting:** cloud (Google, through an OpenAI-compatible layer)
**Connection:** `provider: openai-compatible`,
`baseUrl: https://generativelanguage.googleapis.com/v1beta/openai`, model `gemini-3.7-flash`
**Key reference:** `google.apiKey`

The cheap and fast model of the line: $0.375 and $1.875 per million tokens — five times
cheaper than Gemini-3.1-Pro with the same context of 1,048,576 tokens.
Skill scores 77–86: bulk work with text (translations, summaries, drafts) and simple code. It
is not worth taking for complex requirements analysis or architecture.

Like the senior models of the line, it accepts **audio and video** (`audio/*`, `video/*`) as
input.

## How to obtain the key

**The key is the very same** as for the other Gemini models (`google.apiKey`). If it has
already been entered, this model will work on its own.

If there is no key yet:

1. Open [Google AI Studio](https://aistudio.google.com/apikey) and sign in with a Google
   account.
2. Press **Create API key**, pick a Google Cloud project.
3. Copy the key (it starts with `AIza`).
4. Link the project's billing if the jobs are long and frequent.
5. In AI2P: **Settings → Catalogs → AI models → Gemini-3.7-Flash → «Set API key»**.

## Hardware requirements

None: the computation happens on the provider side. Internet access to
`generativelanguage.googleapis.com` is required.

## Common errors

* **404 "model not found"** — the id has changed; check it against the `GET /models` list.
* **429 "resource exhausted"** — you have run into the rate of the free tier.
* **The quality is lower than expected** — the task is harder than the model's niche; move the
  project's "price ↔ quality" slider towards quality or set the executor by hand.
