# Плагин «dev.to» (publish.devto)

Публикация статей на [dev.to](https://dev.to) агентом через Forem API.

## Подключение

1. На dev.to: **Settings → Extensions → DEV Community API Keys** — создайте ключ.
2. В AI2P: **Настройки → Плагины и MCP → dev.to → Инициализировать**, затем вставьте ключ в поле «Секрет» и нажмите «Сохранить».
   Ключ хранится в `secrets/` этого сервера (`plugin.publish.devto.token`), в задачу, config.json и базу организации не попадает.

## Инструмент агента `devto_publish`

| Параметр | Что это |
|---|---|
| `file` | путь к `.md` в папке проекта (обязательно) |
| `published` | `true` — опубликовать, `false` (по умолчанию) — черновик |

Файл — Markdown с шапкой front matter dev.to:

```
---
title: Заголовок статьи
description: Короткое описание
tags: ai, devops, tools
canonical_url: https://example.com/blog/post
cover_image: https://example.com/img/cover.png
---
Текст статьи…
```

* Первый вызов — `POST /api/articles`; в шапку файла дописываются `devto_id` и `devto_url`.
* Повторный вызов для того же файла — `PUT /api/articles/{devto_id}`: обновляется та же статья.
* Строка `published` в отправляемой шапке переписывается значением флага — опубликовать черновик случайно нельзя.
* Ответ инструмента — адрес статьи.

## Ограничения

* **Картинки — только адресами.** API dev.to не принимает загрузку файлов: обложка и картинки в тексте должны быть публичными https-ссылками (блог сайта, репозиторий).
* Действие записано в справочник действий (`AI2P.Plugins.DevTo.Publish`): правило безопасности deny/confirm на этот код закрывает публикацию.
* Medium так не подключить: новые интеграционные токены Medium не выдаёт, там публикует человек импортом по адресу статьи.
