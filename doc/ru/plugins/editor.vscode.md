# Плагин «VS Code»

Плагин готовит этот сервер к связи проектов с VS Code (карточка проекта → «Подключить VS Code»).
Действий агенту у него нет — он отвечает за программы:

| Программа | Зачем | Как находится |
|---|---|---|
| Visual Studio Code | редактор, к которому подключается проект | сначала ищется установленный (команда `code` в PATH); не найден — «Установить» скачивает **последнюю** стабильную версию портативным архивом в каталог пакетов |

## Несколько копий VS Code

Если на машине несколько копий (VS Code, Insiders, VSCodium, Cursor …), укажите в строке
«Visual Studio Code» окна плагина путь к той, что подключать к проектам
(Windows: `<каталог VS Code>\bin\code.cmd`). Эта копия — **внутренняя**: в форме выбора копии
у проекта она помечена «внутренняя» и выбрана по умолчанию; остальные копии доступны для выбора, как раньше.

## Включение

Когда VS Code найден или установлен, плагин включается сам — отдельно нажимать «Инициализировать» не нужно.
Выключенный вручную плагин сам не включается.

## Связь с проектом

При «Подключить VS Code» в карточке проекта сначала проверяется плагин. Не подключён —
запускается подключение: найденное берётся, недостающее ставится в фоне. Пока VS Code не найден,
подключить проект нельзя — панель так и пишет «VS Code на этом сервере не найден».
Действие требует роли администратора этого компьютера (раздел плагинов).
