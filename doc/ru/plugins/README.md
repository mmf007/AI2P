# Плагины и MCP: документы плагинов

Каталог с документами плагинов: по файлу на **код плагина** (`tool.ffmpeg.md`). Документ
открывается кнопкой **«i»** в строке плагина: **Настройки → Плагины и MCP**.

Плагин — это запись организации плюс файл-манифест `plugins/<код>/plugin.json` в каталоге
данных. Манифест описывает, что плагин умеет (действия, они же инструменты ИИ-агента), где
взять внешнюю программу и какие у записи настройки; сама программа и путь к ней — величина
**этого компьютера**, она не реплицируется.

## Оглавление раздела

* [editor.blender](editor.blender.md) — Blender VSE — шлюз `editor.blender`
* [editor.openshot](editor.openshot.md) — OpenShot — шлюз `editor.openshot` (запасной)
* [editor.resolve](editor.resolve.md) — DaVinci Resolve (OTIO)
* [editor.shotcut](editor.shotcut.md) — Shotcut / Kdenlive (MLT XML)
* [tool.ffmpeg](tool.ffmpeg.md) — Видео конвертор (ffmpeg) — плагин `tool.ffmpeg`
* [trainer.musubi](trainer.musubi.md) — Musubi Tuner (LoRA) — плагин `trainer.musubi`

## Что общего у всех плагинов

**Действия узкие и именованные.** Инструмент агента делает ровно одну названную работу, а её
параметры лежат в манифесте и в настройках записи. Действий вида «выполнить командную строку»
в системе нет намеренно: это исполнение произвольного кода с правом писать файлы, и правилом
безопасности его не сузить.

**Инструмент плагина закрывается правилом безопасности** — у каждого действия есть своя
запись справочника действий, которую заводит инициализация плагина. Инструмент без такой
записи не публикуется вовсе.

**Пути ограничены.** Читать и писать плагин может в папке проекта и во внешних каталогах,
открытых правилами безопасности задачи, — больше нигде.

**Установка локальна.** Описание плагина реплицируется на все серверы организации, а
найденная программа и её путь живут в `config.json` того компьютера, где она стоит.

## Как добавить документ нового плагина

Положите сюда файл `<код плагина>.md` — ровно тем кодом, каким плагин назван в манифесте
(`tool.ffmpeg`). Такой же файл заведите во всех остальных языках: состав документов у языков
обязан совпадать. Оглавление выше руками не правится — его собирает по составу каталога
скрипт `test/t18s1/mktoc.py`, и запустить его надо после добавления файла.

Внешние адреса в этих документах пишите **полными**, со схемой `https://` — документ
открывается кнопкой «i» внутри страницы приложения, и относительная ссылка там мёртвая.
