# Наборы опыта: стили работы

Каталог с документами **наборов опыта** — по файлу на **код набора** (`style.tdd.md`).
Документ открывается кнопкой **«i»** в строке набора: **Настройки → Опыт → Наборы**.

Набор опыта — это готовая пачка записей опыта, которую человек ставит одной кнопкой и
получает дисциплину работы агентов «из коробки»: как ревьюим, как пишем тесты, как ведём
отчёты. Файл набора — `packs/<код>/pack.json` в каталоге данных; записи ложатся в ту
область, которую вы выбрали при установке (общие правила организации, опыт проекта или узел
шаблона), и снимаются целиком одной кнопкой.

## Оглавление раздела

* [style.strict-review](style.strict-review.md) — Строгое код-ревью
* [style.tdd](style.tdd.md) — Разработка через тесты
* [style.research-report](style.research-report.md) — Исследование и отчёт
* [style.experience-analysis](style.experience-analysis.md) — Анализ опыта

Последний в списке стоит особняком: `style.experience-analysis` — это не стиль работы, а
шаблон задач для периодического разбора накопленного опыта.

## Что общего у всех наборов

**Записи — правила, а не рассуждения.** Каждая запись коротка, говорит об одной вещи и
меняет поведение исполнителя. Пересказ общеизвестного в набор не попадает: он съедает предел
опыта в задании и вытесняет то, что действительно нужно.

**У записи проставлен навык.** Правило про тесты достаётся тому, кто пишет тесты, правило
про отчёт — тому, кто пишет отчёт. Запись без навыка в задание не попадёт вовсе — кроме
записей с пометкой «загружать всегда», и таких в дистрибутиве ровно одна.

**Ничего проектного.** В поставляемых наборах нет ни названий продуктов, ни путей файлов, ни
кодов задач: набор ставится в любую организацию. Своё, проектное, дописывайте рядом —
обычными записями опыта проекта.

**Набор ставится и снимается целиком.** Установка помечает свои записи служебным тэгом
`pack:<код>`; снятие убирает по нему ровно их и не трогает ни ваши записи, ни ваши правки
текстов. Отредактированная вами запись остаётся вашей: повторная установка её не перепишет.

## Как добавить документ нового набора

Положите сюда файл `<код набора>.md` — ровно тем кодом, каким набор назван в `pack.json`.
Такой же файл заведите во всех остальных языках: состав документов у языков обязан совпадать.
