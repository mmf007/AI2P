# Установка ПО CLI-агентов

## Что такое CLI-модель

В справочнике моделей три вида размещения:

| Иконка | Вид | Что это |
|---|---|---|
| монитор | **локальная** | модель работает на этом компьютере (ComfyUI, llama.cpp) |
| облако | **облачная** | AI2P сам ходит в API провайдера с ключом |
| облако внутри монитора | **CLI-агент** | на компьютере стоит программа вендора (Claude Code, Codex CLI, Qwen Code …), а она уже сама ходит в облако по подписке |

CLI-модель — это локальное ПО, которое работает с облаком. Поэтому:

* **запись справочника и исполнитель — общие** на всю организацию (как у облачной модели);
* **программа CLI ставится на КАЖДОМ сервере отдельно** — задания CLI-исполнителя идут на том сервере, где программа установлена и где выполнен вход (кнопка с ключом в строке модели);
* ставит программу **администратор этого сервера** (локальный admin): форма модели открывается на любом сервере, кнопка «Установить» / «Обновить» и выбор способа установки доступны только ему.

## Что ставится

Окно установки CLI-модели (Настройки → Модели ИИ → карандаш → «Установить») собирает список само, по команде CLI из профайла модели:

| Модель | Программа | Как ставится |
|---|---|---|
| Claude-*_cli | Claude Code (`claude`) | npm `@anthropic-ai/claude-code` |
| GPT-*_cli | Codex CLI (`codex`) | npm `@openai/codex` |
| Qwen*_cli | Qwen Code (`qwen`) | npm `@qwen-code/qwen-code` |
| Gemini-*_cli | Antigravity CLI (`agy`) | вручную, AI2P только ищет команду в PATH |
| Grok-*_cli | Grok Build (`grok`) | вручную |
| Kimi-*_cli | Kimi CLI (`kimi`) | вручную (`uv tool install kimi-cli`) |
| Mistral-*_cli | Mistral Vibe (`vibe`) | вручную (`uv tool install mistral-vibe`) |

Для npm-программ нужен **Node.js 20 или новее**. Сначала он ищется в системе (команда `node` в PATH); не нашёлся — ставится портативный Node.js 24 LTS в каталог пакетов AI2P (`<каталог пакетов>/nodejs`). Перед скачиванием проверяется каталог дистрибутивов (Настройки → Сервер): если там уже лежит `node-v24.21.0-win-x64.zip` (Linux — `…-linux-x64.tar.gz`, macOS — `…-darwin-arm64.tar.gz`) или распакованный архив, он берётся как есть, без сети.

Если всё уже стоит, кнопка называется **«Обновить»**: npm-программа переустанавливается до последней версии (`npm install <пакет>@latest`).

## Для пользователя или общая установка

В окне установки есть флажок **«Только для текущего пользователя»** (по умолчанию включён). Выбор запоминается в config.json ЭТОГО сервера.

**Для пользователя** (флажок стоит):

* команда: `npm install --prefix "<каталог пакетов>/cli/<программа>" <пакет>@latest`;
* права администратора **не нужны**;
* программа видна только AI2P: при запуске CLI-агента AI2P сам добавляет её каталог и каталог своего Node.js в PATH процесса. В терминале пользователя команды `claude` при этом нет — для входа в CLI пользуйтесь кнопкой входа в строке модели либо вызывайте программу полным путём (`<каталог пакетов>\cli\claude-code\claude.cmd` на Windows, `<каталог пакетов>/cli/claude-code/bin/claude` на Linux/macOS).

**Общая** (флажок снят):

* команда: `npm install -g <пакет>@latest` (на Windows — с `--prefix "<каталог системного Node.js>"`, этот каталог уже есть в общем PATH);
* программа доступна всем пользователям компьютера и в любом терминале;
* нужен **Node.js, установленный в систему** (не портативный из каталога пакетов AI2P) — иначе установка откажет и подскажет, как поставить Node.js;
* почти всегда нужны **права администратора** (Windows — каталог Program Files, Linux/macOS — /usr или /usr/local).

### Если прав не хватило

Окно установки покажет ошибку с точной командой. Сделайте одно из трёх:

1. **Выполнить команду самому с правами администратора.**
   * Windows: Пуск → «Терминал» (или PowerShell) → правая кнопка → «Запуск от имени администратора», вставить команду из сообщения, например
     `"C:\Program Files\nodejs\npm.cmd" install -g @anthropic-ai/claude-code@latest --prefix "C:\Program Files\nodejs"`
   * Linux / macOS: `sudo npm install -g @anthropic-ai/claude-code@latest`
   * Затем в окне установки нажать **«Обновить»** — AI2P найдёт программу в PATH и покажет её как установленную.
2. **Запустить AI2P с правами администратора (root)** и повторить установку из окна — тогда общая установка пройдёт сама. Окно установки прямо пишет, запущена ли AI2P с такими правами. Это альтернатива, а не рекомендация: сервер с правами администратора может всё, в том числе его CLI-агенты.
   * Windows: остановить AI2P, запустить `AI2P.Server.exe` через «Запуск от имени администратора» (либо службу — от учётной записи с правами администратора, см. «Запуск AI2P сервисом»).
   * Linux / macOS: `sudo ./AI2P.Server` (либо служба systemd с `User=root`).
3. **Поставить флажок «Только для текущего пользователя»** и установить ещё раз — прав администратора не нужно.

## Программы, которые ставятся вручную

У Antigravity, Grok Build, Kimi и Mistral Vibe автоматической установки нет: поставьте программу по инструкции вендора так, чтобы команда была в PATH пользователя, под которым работает AI2P, и нажмите «Обновить». Окно установки покажет её как установленную.

## Вход в CLI

Установка ставит программу, но не входит в учётную запись вендора. После установки нажмите кнопку с ключом в строке модели: у Claude Code вход идёт формой AI2P, у остальных — команда входа в терминале этого компьютера.
