# Установка AI2P и где лежат её данные

Эта глава отвечает на два вопроса: **куда ставится программа** и **где после этого лежат
её рабочие файлы** — конфигурация, база задач, журналы и ключи. Второй вопрос важнее, чем
кажется: рабочие файлы переживают обновление версии, их копируют при переносе на другой
компьютер, и именно их нельзя потерять.

---

## 1. Три способа поставить

| Способ | Что это | Когда удобно |
|---|---|---|
| **Пакет установки** | один файл `AI2P_v_1_NN_…` (или `AI2P_full_v_1_NN_…` — с рантаймом внутри), ставится двойным щелчком | обычный случай на Windows |
| **Скрипт установки** | `install.cmd` / `install.sh` из каталога выкладки | когда выкладка уже скачана и каталог выбирают руками |
| **Просто выкладка** | распакованный каталог, запускается `AI2P.Server.exe` | проба, переносная установка на флешке |

Пакет установки на Windows спрашивает, ставить **для всех пользователей** или **только для
меня**. От этого зависит каталог программы:

* **для всех** — `C:\Program Files\AI2P` (нужны права администратора);
* **только для меня** — `C:\Users\<вы>\AppData\Local\Programs\AI2P`.

На Linux и macOS установка идёт в домашний каталог: по умолчанию `~/ai/AI2P`.

---

## 2. Где лежат рабочие файлы

Правило одно: **рабочие файлы лежат рядом с программой, если в её каталог можно писать.**

Рядом с программой — это `config.json`, каталог данных `data/` (база сервера, базы
организаций, файлы проектов), журналы `logs/` и ключи `secrets/`.

В каталог программ Windows (`C:\Program Files`) обычный пользователь писать **не может**, и
это не поломка, а правило системы: иначе любой пользователь компьютера мог бы подменить
`AI2P.Server.exe`, который потом запускает администратор. Поэтому у установки «для всех»
рабочие файлы лежат отдельно:

| Установка | Программа | Рабочие файлы |
|---|---|---|
| Windows, «для всех» | `C:\Program Files\AI2P` | **`C:\ProgramData\AI2P`** |
| Windows, «только для меня» | `…\AppData\Local\Programs\AI2P` | рядом с программой |
| Выкладка в свою папку (`D:\AI2P`) | `D:\AI2P` | рядом с программой |
| Linux/macOS, `~/ai/AI2P` | `~/ai/AI2P` | рядом с программой |
| Linux/macOS, `/opt/ai2p` | `/opt/ai2p` | `/var/lib/ai2p`, а без прав на него — `~/.local/share/ai2p` |

`C:\ProgramData\AI2P` — общий каталог **этого компьютера**: установка одна, данные общие, и
служба (она работает от имени системы) видит те же данные, что и человек. Установщик заводит
этот каталог и открывает его на запись всем пользователям компьютера; при удалении программы
он **остаётся** — это ваши данные.

### Как узнать наверняка

При старте программа сама говорит, где её рабочие файлы:

```
AI2P: каталог программы C:\Program Files\AI2P\ закрыт на запись —
рабочие файлы (config.json, data, logs, secrets) лежат в C:\ProgramData\AI2P
```

Та же строка попадает в технический журнал (`logs/ai2p-<дата>.jsonl`), а полные пути
конфигурации и каталога данных видны в журнале сразу после запуска.

### Как задать каталог самому

| Способ | Что делает |
|---|---|
| `AI2P.Server.exe --config D:\мойAI2P\config.json` | взять именно этот `config.json`; `data/`, `logs/` и `secrets/` будут рядом с ним |
| переменная окружения `AI2P_HOME=D:\мойAI2P` | то же самое, но задаётся один раз для службы, контейнера или ярлыка |

Заданный так каталог сильнее любых правил: программа в него не вмешивается.

## 3. Обновление версии

Установка поверх старой **не трогает** рабочие файлы: `config.json`, `data/`, `secrets/`
остаются как были. Рядом с программой ложится `config.new.json` — конфигурация новой версии,
и при первом старте программа сливает их: за основу берётся новая (в ней есть все новые
параметры с умолчаниями), поверх ложатся ваши значения. О слиянии она говорит строкой
в консоли, а рядом с рабочим `config.json` остаётся копия применённого файла
(`config.new.json.applied`) — по ней видно, что и когда приехало.

Слияние идёт **ровно один раз на версию**: повторный запуск ничего не переписывает.

### Данные, оставшиеся рядом с программой

Если раньше вы ставили AI2P в `C:\Program Files\AI2P` и запускали его **от имени
администратора**, данные могли завестись прямо там. Тогда после обновления программа скажет:

```
AI2P: рядом с программой остался каталог данных C:\Program Files\AI2P\data от прежней
работы — теперь данные лежат в C:\ProgramData\AI2P; при надобности перенесите его туда руками
```

Сама она эти данные **не переносит**: перекладывать базу за спиной человека нельзя. Настройки
(`config.json` прежней установки) при этом забираются с собой — порт, имя хоста и каталоги
задавали вы, и терять их незачем. Чтобы перенести и данные: остановите AI2P, скопируйте
каталог `data` (а также `secrets`, если он там есть) в новый каталог рабочих файлов и
запустите снова.

### `AI2P_HOME: parameter not set` при обновлении на Linux/macOS

Версии **1.100 и 1.101** обрывали обновление на этой строке:

```
./install.sh: 147: AI2P_HOME: parameter not set
```

Не копировалось вообще ничего, и установленная версия оставалась прежней. Виноват был сам
установщик: он читал переменную `AI2P_HOME`, которой у обычной установки нет. С версии
**1.102** такого больше не бывает.

Если у вас на руках только выкладка 1.100 или 1.101, обновление ею всё-таки сделать можно —
достаточно задать переменную пустым значением:

```sh
AI2P_HOME= ./install.sh ~/ai/AI2P
```

То же лекарство годится для `makeAsServise.sh` тех же версий.

## 4. Служба операционной системы

Служба и обычный запуск пользуются **одним и тем же** каталогом рабочих файлов — он выбирается
по каталогу программы, а не по правам того, кто запустил. Значит, сделав установку службой
(`makeAsServise`, см. [service](service.md)), вы не получите вторую базу «для системы».

---

## 5. Если программа не запускается

Запущенная ярлыком AI2P — обычная консольная программа: при аварии на старте она **пишет
причину словами и держит окно**, пока не нажмёте клавишу (само окно закроется через минуту).
Что бывает:

| Что видно | Что это | Что делать |
|---|---|---|
| `AI2P: запуск не удался — Access to the path … is denied` | рабочие файлы задали в каталоге, куда писать нельзя | указать другой каталог (`AI2P_HOME`, `--config`) |
| `Рабочие файлы AI2P некуда положить` | закрыты и каталог программы, и оба каталога данных | то же самое: задать каталог явно |
| `AI2P уже запущен (…) — открываю браузер и выхожу` | это не ошибка: экземпляр на этом компьютере один, и он уже работает | ничего |
| окно закрывается сразу и молча | версия **старее 1.100**: авария на старте там уносила окно вместе с сообщением | обновиться или запустить `AI2P.Server.exe` из консоли и прочитать вывод |
