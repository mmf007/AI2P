# AI2P в VS Code

AI2P умеет работать внутри VS Code: карточка проекта, рабочая среда, настройки, документация
и карточки задач открываются панелями редактора, рядом с кодом проекта. Это тот же интерфейс
AI2P, что и в браузере, только без верхнего меню, закладок, левого тулбара и навигатора, а
светлая или тёмная тема берётся из VS Code.

Всё работает через расширение **AI2P** для VS Code. Оно поставляется вместе с AI2P (файл
`ai2p-<версия>.vsix` в каталоге программы), его версия всегда равна версии AI2P, и ставит его
сам AI2P — из Marketplace ничего качать не нужно.

## Что нужно

* AI2P и VS Code на **одном компьютере**: панели ходят на сервер по адресу `http://localhost`.
* У проекта на этом сервере задан **каталог проекта**. Каталог у каждого сервера свой: если на этом сервере каталога нет, подключить VS Code к
  проекту здесь нельзя, и кнопок подключения нет.
* VS Code установлен обычным образом (см. «Ограничения»).

## Подключение проекта

1. Откройте в AI2P карточку проекта, закладку **«Настройка»**, режим правки.
2. Нажмите **«Подключить VS Code»**. Если на компьютере найдено несколько копий VS Code,
   сначала появится окно **«Выберите копию VS Code»**: отметьте нужную. Выбор запоминается для этого проекта **на
   этом сервере** и на другие серверы кластера не переезжает — разные проекты могут
   работать с разными копиями.
3. AI2P делает сам:
   * ставит или обновляет расширение в выбранной копии VS Code;
   * создаёт в каталоге проекта файл `.ai2p/link.json` — адрес сервера, код организации,
     проект и путь к серверу. **Секретов в этом файле нет**;
   * выпускает **токен устройства** и передаёт его в VS Code ссылкой `vscode://ai2p.ai2p/link`.
     VS Code спросит, разрешить ли расширению открыть ссылку, — разрешите. Токен хранится в
     защищённом хранилище VS Code (SecretStorage), а не в файлах проекта;
     Ссылка строится по схеме выбранной копии (`vscode-insiders://`, `vscodium://`, `cursor://`,
     `windsurf://`), поэтому токен попадает именно в неё;
   * по флажкам окна подключения — **«Добавить .ai2p/ в .gitignore»** и **«Открыть проект в
     VS Code»** — дописывает `.gitignore` и открывает папку проекта.

Проект можно подключить и при создании: если VS Code найден и каталог задан, в форме нового
проекта есть флажок «Подключить VS Code».

Расширение просыпается **только** в папках, где лежит `.ai2p/link.json`: в остальных проектах
VS Code его не видно.

На закладке **«Настройка»** состояние видно и без режима правки: «Подключён к VS Code» или
«Не подключён к VS Code», имя и **версия** копии VS Code и кнопка **«Открыть проект в VS Code»**.
Кнопки «Подключить», «Отключить» и выбор копии — вторым рядом, только в режиме правки.

Если значка **AI2P** в Activity Bar нет — расширение не поставилось: в выкладке нет файла
`ai2p-<версия>.vsix` (при подключении AI2P предупреждает об этом всплывающим сообщением).
Проверить можно в VS Code: **Extensions** → поиск `ai2p`.

## Первое открытие папки: «Trust Folder»

Когда VS Code открывает папку проекта **впервые**, он спрашивает, доверяете ли вы её автору
(окно **«Do you trust the authors of the files in this folder?»**, кнопки **«Yes, I trust the
authors»** / **«Trust Folder»** и **«No, I don't trust the authors»**). Пока папка не помечена
доверенной, VS Code держит её в ограниченном режиме (Restricted Mode), и расширения в ней
работают не полностью.

Из-за этого при самом первом подключении ссылка с токеном, которую AI2P передаёт в VS Code,
**теряется**: пока вы читаете окно доверия, расширение ещё не может её принять, и панели AI2P не
открываются. Что делать — **один раз**:

1. В окне доверия нажмите **«Yes, I trust the authors»** (**«Trust Folder»**).
2. **Закройте** это окно VS Code (или папку: **File → Close Folder**).
3. Снова нажмите в AI2P **«Открыть проект в VS Code»** (или **«Подключить VS Code»**).

Теперь папка доверенная, VS Code больше не спрашивает, ссылка доходит, и проект открывается сразу.
Повторять это для той же папки не нужно — только для каждой новой папки проекта.

## Меню и панели

Слева в Activity Bar появляется значок **AI2P**. В его меню четыре пункта:

| Пункт | Что открывает |
|---|---|
| **Проект** | карточку проекта |
| **Окружение** | рабочую среду и архивы (пункт виден, только если архивы есть) |
| **Настройки** | настройки AI2P |
| **Документы** | эту документацию |

Те же действия есть в палитре команд (`Ctrl+Shift+P`) с приставкой **«AI2P:»**:
«AI2P: Проект», «AI2P: Окружение», «AI2P: Настройки», «AI2P: Документы», «AI2P: Открыть
задачу…», «AI2P: Подключить проект из AI2P», «AI2P: Отключить VS Code», «AI2P: Запустить
сервер», «AI2P: Проверить обновление расширения». Подписи переведены на пять языков AI2P и
берутся по языку VS Code.

Каждый пункт открывает одну панель: повторный выбор выводит уже открытую вперёд. **Задача**,
выбранная в любой панели (дерево, доска, таблица, диаграмма, Inbox, ссылка в тексте),
открывается **отдельной панелью** рядом — карточкой одной задачи. Открытые панели VS Code
восстанавливает после перезапуска.

**Тема.** Светлая или тёмная тема берётся из VS Code и меняется на лету во всех открытых
панелях, когда вы переключаете тему редактора. Свою тему AI2P в браузере это не меняет.

**Язык.** Панели говорят на языке VS Code, если это один из языков AI2P (русский, английский,
испанский, португальский, китайский); иначе — на языке установки AI2P.

## Сервер AI2P

Если сервер не запущен, расширение запускает его само при открытии первой панели — один раз
на компьютер, даже если открыто несколько окон VS Code. Сервер живёт отдельно от VS Code:
закрытие редактора его не гасит.

Если сервер перезапустили, панели сами дождутся его и перезагрузятся — нажимать ничего не
нужно.

## Вход и отзыв токена

В панелях нет формы входа: VS Code входит **токеном устройства**, выпущенным при подключении,
от имени того человека, который нажал «Подключить VS Code», и с его правами. Токен действует
только на этом сервере.

Свои токены видно в AI2P: **Настройки → «Уведомления» → «Мои устройства (VS Code)»** — устройство,
проект, дата выпуска и последний вход. Кнопка **«Отозвать»** закрывает доступ: со следующего
обращения панель покажет «Нужно подключить VS Code». Каждый видит и отзывает только свои токены.

## Отключение

На закладке «Настройка» проекта нажмите **«Отключить VS Code»**: AI2P удалит `.ai2p/link.json` и
отзовёт все ваши токены этого проекта. Само расширение остаётся — оно общее для всех проектов.

Команда **«AI2P: Отключить VS Code»** в палитре стирает токен только на этом компьютере;
чтобы закрыть его и на сервере, отзовите токен в «Моих устройствах».

## Обновление расширения

Расширение обновляется вместе с AI2P:

* при старте сервер сверяет версию расширения во всех запомненных копиях VS Code и, если оно
  отстаёт, ставит новое фоном;
* само расширение при запуске сравнивает свою версию с версией сервера и, если отстаёт,
  предлагает **«Обновить»**; после обновления VS Code попросит перезагрузить окно (Reload Window).

Проверить вручную — командой «AI2P: Проверить обновление расширения».

## Ограничения

* **Только localhost по HTTP.** Панели VS Code не принимают самоподписанный сертификат,
  поэтому даже на сервере с HTTPS встроенный режим ходит на `http://localhost`. Подключить
  VS Code к серверу на другом компьютере нельзя.
* **Форки VS Code** (VS Code Insiders, VSCodium, Cursor, Windsurf) AI2P находит и может
  выбрать, но проверялся только обычный VS Code.
* **macOS и Linux.** Расширение проверено на Windows, macOS и Linux.
* Если компьютер уснул или пропала сеть, а сервер не останавливался, панель может показать
  окно переподключения дольше обычного; закройте и откройте её заново.
* Внутри панелей не работают окна входа и формы, требующие обычного входа: вход — только по
  токену.
