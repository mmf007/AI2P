# Импорт задач из Trello — инструкция по подключению

Импорт переносит карточки Trello в задачи AI2P (ТЗ п. 2.10, гл. 11). Для подключения
нужны две строки от Trello — **API key** и **Token** — и одна запись в справочнике
импортов. По шагам:

## 1. Получить API key

Trello выдаёт ключи через страницу интеграций (Power-Ups):

1. Войдите в Trello в браузере и откройте <https://trello.com/power-ups/admin>.
2. Нажмите **«New»** (создать новую интеграцию). Заполните обязательные поля:
   * **Name** — любое, например `AI2P import`;
   * **Workspace** — ваше рабочее пространство;
   * **Email / Author** — ваши.
   Поле «Iframe connector URL» можно оставить пустым.
3. Откройте созданную интеграцию → вкладка **«API key»** → кнопка
   **«Generate a new API key»**.
4. Скопируйте значение поля **API key** (строка из букв и цифр).

## 2. Получить Token

На той же странице, справа от поля API key, есть ссылка **«Token»**
(в тексте «you can manually generate a Token»):

1. Нажмите её — откроется страница авторизации Trello.
2. Нажмите **«Разрешить» (Allow)** внизу страницы.
3. Скопируйте показанный **токен** (длинная строка).

Токен даёт доступ к доскам вашего аккаунта — храните его как пароль.

## 3. Создать источник в справочнике импортов

**Настройки → вкладка «Справочники» → «Справочник импортов» → «Добавить»:**

| Поле | Что вписать |
| --- | --- |
| Имя источника | любое, например `Trello основной` |
| Вид | Trello |
| Логин в Trello | ваш **username** — виден в профиле Trello как `@имя` (вписывать без `@`) |
| Фильтр | подстрока имени доски, например `AI2P`; пусто — все доски |
| Активна | пока недоступно — включится само после шага 4 |

Нажмите **«Сохранить»**. Кнопки ввода ключа и токена появляются у **сохранённой** записи:
значение кладётся в хранилище сразу, поэтому до сохранения неизвестно, чьё оно.

## 4. Ввести ключ API и токен (v1.65)

Откройте сохранённый источник кнопкой **«редактировать»** — в форме появились две кнопки:

1. **«Установить ключ API»** — вставьте строку из шага 1, «Сохранить».
2. **«Установить токен»** — вставьте строку из шага 2, «Сохранить».

Каждая кнопка спрашивает **ровно одно поле**. Старое значение никогда не показывается —
чтобы заменить ключ, вводится новый. Под формой видно состояние: «Ключ API: установлен,
источник — организация», то же для токена.

**Ключ и токен легко перепутать местами**, а Trello отвечает на это невнятным «invalid key».
Поэтому форма сверяет их вид и предупреждает: **ключ API — ровно 32 знака** `0–9 a–f`,
**токен — 64 таких же знака** либо строка, начинающаяся с `ATTA`. И то и другое —
**не «Secret»**: секрет интеграции с той же страницы токеном не является и в AI2P не нужен.

**Кнопка «Проверить подключение»** (рядом с кнопками ввода, работает, когда заполнены оба
значения) спрашивает у Trello «кто я» и сразу отвечает словами: принят ли ключ, принят ли
токен, какому аккаунту выдан токен и совпадает ли он с логином источника. Проверять
подключение здесь дешевле, чем ловить отказ при первом импорте.

**Где эти значения лежат.** В базе данных вашей организации, **зашифрованными** ключом
организации (как ключи API моделей): они сами доезжают до всех серверов организации,
а расшифровать их может только сервер, которому ключ организации выдан. Вписывать что-либо
в `secrets.json` больше не нужно.

**Пока не введены оба значения, источник не может быть активным** — переключатель «Активна»
заблокирован. Как только введено последнее из двух, источник **включается сам**; дальше
активность переключаете вы.

**Установки, где ключи уже вписаны в `secrets.json`,** продолжают работать: значения
читаются в порядке «организация → `secrets.json` → переменная окружения», а при первом
старте новой версии переносятся из файла в организацию — форма сразу покажет
«установлен». Переменные окружения `TRELLO_API_KEY` / `TRELLO_TOKEN` тоже по-прежнему
работают и никуда не переносятся: их задают снаружи нарочно.

**Два аккаунта Trello.** У каждого источника, заведённого начиная с v1.65, **своя** пара
ключ/токен — заведите второй источник и введите в него другие значения. У источников,
существовавших до v1.65, пара общая (ссылки `trello.apiKey` / `trello.token` в параметрах
записи): чтобы развести их, заведите источник заново.

## 5. Запустить импорт

1. Выберите **проект** (в шапке или на вкладке проекта) — импорт всегда идёт в текущий
   проект.
2. В списке задач нажмите кнопку-иконку **облако со стрелкой** («Импорт задач») —
   она видна только при выбранном проекте.
3. В диалоге выберите источник и чекбоксы:
   * **добавлять новые** (включён по умолчанию) — карточки, которых ещё нет, станут задачами;
   * **обновить существующие** — у ранее импортированных задач обновятся заголовок,
     описание и срок из Trello (локальные правки этих полей будут перезаписаны).
4. Нажмите **«Импортировать»**. Итог покажется сообщением: «добавлено X, обновлено Y,
   пропущено Z»; запись `import.run` появится в «Истории работ».

## Что именно импортируется

* Берутся **открытые карточки открытых досок** указанного логина; доски фильтруются по
  подстроке имени (пустой фильтр — все).
* Карточка → задача со статусом **«черновик»**: заголовок, срок (due), описание карточки +
  приписка-источник внизу («Импортировано из Trello: доска …, карточка» со ссылкой).
  Исполнителей и приоритет заполняете уже в AI2P.
* **Дубли не создаются**: внешний id карточки запоминается в задаче (`trello:<id>`);
  повторный импорт ту же карточку пропустит или обновит — по чекбоксу.

## Если что-то не работает

| Сообщение | Причина и что делать |
| --- | --- |
| «Ключ Trello не найден (…)» | Ключ API либо токен не введён: откройте источник и нажмите «Установить ключ API» / «Установить токен» (шаг 4). У старой установки — проверьте `secrets.json`: путь к файлу указан прямо в сообщении. |
| «Этот сервер ещё не получил ключ организации…» | Сервер подключён к чужой организации, но заявка не подтверждена её дирижёром — без ключа организации значения нечем зашифровать. Подтвердите подключение (Настройки → Серверы). |
| «Trello не принял КЛЮЧ API…» (ответ Trello «invalid key») | Ключ не тот: чаще всего в поле ключа оказывается **токен** — сообщение это называет прямо и показывает длину введённого значения. Повторите шаг 1 и введите ключ заново. |
| «Trello не принял ТОКЕН…» («invalid token») | Токен неверный, отозван или в его поле попал ключ/«Secret» — повторите шаг 2. |
| «Trello отказал в доступе…» | Ключ и токен приняты, но у аккаунта, которому выдан токен, нет прав на эту доску или карточку. |
| «Trello не нашёл запрошенное (HTTP 404…)» | Логин (username) не существует либо карточка недоступна аккаунту токена — сверьте с профилем Trello. |
| Импорт прошёл, но «добавлено 0» | Фильтр не совпал ни с одной доской, или у участника нет открытых карточек; попробуйте с пустым фильтром. |

Сообщения приходят целиком в само окно импорта — их не нужно вылавливать из всплывающей
подсказки. Подробности запросов — в логах приложения (`logs/*.jsonl`, записи
`TrelloImporter`): по какой ссылке и из какого хранилища взяты ключ и токен, какой они
длины (сами значения в лог не пишутся никогда), какой ответ вернул Trello.


## Импорт одной карточки по ссылке (v1.50)

Рядом с кнопкой массового импорта в списке задач есть кнопка **«Импорт задания по URL»**:

1. Вставьте ссылку на карточку вида `https://trello.com/c/<код>` (кнопка «Поделиться» на
   карточке Trello). Источник переспрашивается, только если активных trello-источников
   несколько — ключи берутся из него.
2. Содержимое карточки подставится **в форму новой задачи**: заголовок, описание, срок.
   **Файлы-вложения карточки скачиваются** в хранилище проекта и вставляются в описание
   ссылками (картинки — превью); вложения-ссылки остаются ссылками. Файл больше 200 МБ
   не скачивается — остаётся ссылкой с пометкой.
3. Дозаполните форму (исполнитель, приоритет) и сохраните. Повторный импорт той же
   карточки дубль не создаст.

ИИ-агентам то же действие доступно инструментом `import_task_from_url` (код действия
`AI2P.Tasks.ImportFromUrl` — правила безопасности deny/confirm применяются как обычно).
