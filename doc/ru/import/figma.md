# Импорт дизайна из Figma — инструкция по подключению

Импорт превращает **область макета Figma** в задачу AI2P: экраны (и, по желанию, элементы
дизайна) приезжают **картинками**, а под каждой картинкой в описании задачи выписаны **все
подписи** этого кадра — тексты кнопок, заголовков, полей, сверху вниз. Так задача «сделай
этот экран» получает и вид, и тексты дословно. Для подключения нужны личный токен Figma
и одна запись в справочнике импортов.

## 1. Получить токен

**API Figma без токена не отвечает вовсе — даже для публичного файла**, который открывается
в браузере без входа. Токен нужен всегда.

1. Войдите в Figma и откройте <https://www.figma.com/settings> → вкладка **Security**.
2. В разделе **Personal access tokens** нажмите **Generate new token**.
3. Имя — любое, например `AI2P import`; срок жизни — по вкусу.
4. Права (scopes): **File content → Read only**. Остальные не нужны.
5. **Generate token** и скопируйте строку. Она начинается с `figd_` и показывается **один раз**.

Токен читает всё, что видно вашему аккаунту, — храните его как пароль. Чужой файл
по ссылке «Anyone with the link can view» токен тоже читает.

## 2. Создать источник в справочнике импортов

**Настройки → вкладка «Справочники» → «Справочник импортов» → «Добавить»:**

| Поле | Что вписать |
| --- | --- |
| Имя источника | любое, например `Figma дизайн` |
| Вид | Figma |
| Активна | пока недоступно — включится само после шага 3 |

Других полей у источника Figma нет: импорт идёт **только по ссылке** на область макета.
Нажмите **«Сохранить»**.

## 3. Ввести токен

Откройте сохранённый источник кнопкой **«редактировать»**, нажмите **«Установить токен»**
и вставьте строку из шага 1. Ключа API у Figma нет: секрет один, кнопка одна. Форма
предупредит, если значение не начинается с `figd_`. Как только токен введён, источник
**включается сам**.

**Кнопка «Проверить подключение»** спрашивает у Figma «кто я» и отвечает словами: принят ли
токен и какому аккаунту он выдан.

Токен лежит в базе организации **зашифрованным** и сам доезжает до всех её серверов.

## 4. Импортировать область макета

1. В Figma **выделите нужную область** — экран, секцию с экранами или страницу — и скопируйте
   ссылку на выделение: правая кнопка → **Copy link to selection** (или `Ctrl+L`). В ссылке
   появится параметр `node-id=…` — это и есть область.
2. В AI2P выберите проект и в списке задач нажмите **«Импорт задания по URL»**.
3. Вставьте ссылку, например
   `https://www.figma.com/design/rqN1QJdU35Q18H5mpUmlFd/Home-Planner?node-id=54965-55076`.
   В окне появятся два выбора:
   * **«Элементы дизайна отдельными картинками»** — выключено: только основные экраны;
     включено: ещё и каждый элемент экрана отдельной картинкой со своими подписями;
   * **«Импортировать весь файл»** — показывается, только если в ссылке **нет** `node-id`.
     Без этой отметки такая ссылка отклоняется: файл целиком бывает огромным.
4. Нажмите **«Импортировать»**: картинки скачаются в проект, содержимое подставится в форму
   новой задачи. Дозаполните форму и сохраните.

### Что считается экраном и элементом

* **Ссылка на фрейм** — это **один экран**: его вложенные фреймы считаются частями экрана.
* **Ссылка на страницу, секцию или группу** — экранами становятся фреймы верхнего уровня
  внутри неё (секции и группы проходятся насквозь).
* **Элементы** (если включены) — компоненты и их экземпляры (внутрь не спускаемся), а также
  вложенные фреймы и группы. Повторяющийся экземпляр одного компонента с теми же подписями
  выносится один раз. Совсем мелкие слои (меньше 8 px) пропускаются.
* Скрытые слои не импортируются.

### Как выглядит описание задачи

Шапка-источник (файл, область, ссылка), дальше по разделу на экран: `## 1. Имя экрана`,
картинка, список **«Подписи:»**. С элементами — подраздел «Элементы экрана …» с той же
раскладкой на каждый элемент. Картинки — PNG в масштабе 2× (очень большой кадр — 1×).

## 5. ИИ-агенты

Агенту то же действие доступно инструментом `import_task_from_url` (код действия
`AI2P.Tasks.ImportFromUrl`), у CLI-агента — командой
`ai2p import <ссылка> --elements true|false [--wholeFile]`. **Оба выбора — вопросы
человеку**: пока агент их не передал, импорт не выполняется, а агент получает просьбу
переспросить. Ссылку без `node-id` агент импортирует только с явного согласия человека.

## 6. Обновление задачи из Figma

У импортированной задачи заполнена **«Ссылка импорта»** — в ней запомнены и область,
и выбор «элементы» (`ai2p-elements=1`) или «весь файл» (`ai2p-whole=1`). Кнопка
**«обновить» → «Из источника импорта»** перечитывает макет тем же способом: заголовок
и **описание переписываются целиком** со свежими картинками. Критерии приёмки,
исполнители, статус и связи не трогаются. Прежние картинки остаются в uploads/ проекта.

## Если что-то не работает

| Сообщение | Причина и что делать |
| --- | --- |
| «Токен Figma не найден по ссылке …» | Токен не введён: шаг 3. |
| «Figma не приняла ТОКЕН…» (`Invalid token`, 403) | Токен неверен, отозван или истёк. Выпустите новый (шаг 1). |
| «Figma отказала в доступе…» (403) | У токена нет права **File content: Read** или файл не виден аккаунту токена. |
| «Figma не нашла файл или узел…» (404) | Неверная ссылка: ключ файла или `node-id`. |
| «В ссылке не указан узел (node-id)…» | Скопируйте ссылку на выделение либо включите «Импортировать весь файл». |
| «Картинка не получена…» под экраном | Figma не отрисовала узел (пустой или слишком большой). Подписи при этом на месте. |
| «Предел картинок за один импорт (300)…» | Слишком много элементов: импортируйте части макета отдельными ссылками. |
| «У источника Figma массового импорта нет» | Кнопка массового импорта не для Figma — используйте «Импорт задания по URL». |

Подробности запросов — в логах приложения (`logs/*.jsonl`, записи `FigmaImporter`); значение
токена в лог не пишется никогда, только длина и префикс.

## Пределы

* Не больше **300 картинок** за один импорт.
* Комментарии макета в чат задачи не переносятся.
* Массового импорта нет — только по ссылке.
