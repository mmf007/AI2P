# Kimi-K3_cli

**Размещение:** облако, подключение **не по API, а по CLI**
**Подключение:** `provider: moonshot`, `transport: cli`, команда `kimi`, модель `kimi-k3`
**Ссылка на ключ:** пусто — **ключ API не нужен**, авторизация сессией CLI

Та же модель, что Kimi-K3, но через терминальный агент вендора **Moonshot Kimi Code** (https://github.com/MoonshotAI/kimi-code). Платится подпиской вендора, в биллинге AI2P стоимость таких заданий равна нулю.

## Важно: коннектора пока нет

Исполнять задания через Moonshot Kimi Code AI2P **пока не умеет**: CLI-коннектор есть только у Claude Code. Поэтому запись заведена **неактивной**. Исполнитель на этой записи получит отказ «по CLI поддерживается только anthropic». Запись нужна, чтобы CLI можно было поставить и войти в него заранее.

## Установка и вход (ключ API не нужен)

1. Установить CLI: `irm https://code.kimi.com/kimi-code/install.ps1 | iex`.
2. Войти: `kimi  →  /login` — в терминале компьютера сервера, под пользователем, от имени которого работает AI2P.
3. Убедиться, что `kimi` доступен из PATH этого пользователя; иначе впишите полный путь в поле `cliCommand`.

Вход: запустить `kimi` и выполнить `/login` — Kimi Code OAuth или ключ Moonshot AI Open Platform.

Ключ запуска без диалога (headless) по открытым источникам не подтверждён — уточните в документации CLI.

Кнопка с ключом в строке справочника моделей показывает команду входа этого CLI.
