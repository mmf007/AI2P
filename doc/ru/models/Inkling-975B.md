# Inkling-975B

**Размещение:** облако (Thinking Machines, **через шлюз OpenRouter**)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://openrouter.ai/api/v1`,
модель `thinkingmachines/inkling`
**Ссылка на ключ:** `openrouter.apiKey`

Открытая модель на 975 млрд параметров (41 млрд активных) под лицензией **Apache 2.0**.
Задумана авторами как **база под дообучение**, а не как рекордсмен: оценки навыков 81–87,
контекст 1 048 576 токенов, цена 0,95 $ и 4,05 $ за миллион. Вход принимает текст,
исходники, картинки и звук.

**Осторожно с фактологией.** В тесте на знание мира (AA Omniscience) модель даёт около
40 % точности при 63 % галлюцинаций: она уверенно придумывает недостающее. Для навыков
`analyze-data` и `text-docs` берите её только там, где результат есть с чем сверить,
а факты приходят в задании, а не из памяти модели.

Своего публичного API у Thinking Machines нет, поэтому запись идёт через шлюз
**OpenRouter**.

## Как получить ключ

**Ключ один на все модели через шлюз** — Muse-Spark-1.2,
Nemotron-3-Ultra, Ling-3.0-Flash и эта
ссылаются на один и тот же `openrouter.apiKey`.

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/).
2. Пополните баланс: **Credits → Add credits**.
3. Откройте [openrouter.ai/keys](https://openrouter.ai/keys) → **Create key**.
4. Скопируйте значение (показывается один раз, начинается с `sk-or-`).
5. В AI2P: **Настройки → Справочники → ИИ-модели → Inkling-975B → «Установить ключ API»**.

**Идентификатор модели живым вызовом не проверен.** У моделей через шлюз он приводится
полным слагом с префиксом вендора (`thinkingmachines/inkling`). Сверьте его запросом
`GET /models` к `https://openrouter.ai/api/v1` — шлюз отдаёт этот список и без ключа.

## Лицензия

| | |
|---|---|
| Условия на результат генерации | определяются **владельцем модели**, а не шлюзом: «Your ownership rights in the Output are set forth in the Model Terms for each Model you use» |
| Коммерческое использование | смотрите Model Terms на карточке модели у шлюза — шлюз отвечает за доставку, а не за права |
| Что обязательно | соблюдать условия и шлюза, и владельца модели; владелец вправе менять свои условия в любой момент |
| Текст условий | <https://openrouter.ai/terms> (редакция от 29.07.2026) плюс Model Terms на карточке модели |
| Плата за генерацию | по токенам — тариф в разделе «Ограничения и стоимость» |

Весов этой модели в открытом доступе нет (на HuggingFace репозиторий не найден, проверено
27.08.2026) — лицензировать нечего, действуют только условия владельца модели и шлюза.

Шлюз, со своей стороны, **по возможности отказывается от обучения на данных** у подключённых
провайдеров, но за точность чужих условий не отвечает и прямо это оговаривает.

Условия шлюза сверены по их тексту 27.08.2026.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `openrouter.ai`.
Веса открыты (Apache 2.0), но 975 млрд параметров на своём компьютере не поднять —
для локальной работы в справочнике есть модели поменьше.

## Частые ошибки

* **404 «No endpoints found»** — потерян префикс вендора или сменился слаг у шлюза.
* **402 «Insufficient credits»** — не пополнен баланс OpenRouter.
* **В результате появились выдуманные факты** — ниша модели; сверяйте результат или
  берите другую модель на фактологические задания.
