# Grok-4.7_cli

**Размещение:** облако, подключение **не по API, а по CLI**
**Подключение:** `provider: xai`, `transport: cli`, команда `grok`, модель `grok-4.7`
**Ссылка на ключ:** пусто — **ключ API не нужен**, авторизация сессией CLI

Та же модель, что Grok-4.7, но через терминальный агент вендора **xAI Grok Build** (https://x.ai). Платится подпиской вендора, в биллинге AI2P стоимость таких заданий равна нулю.

## Важно: коннектора пока нет

Исполнять задания через xAI Grok Build AI2P **пока не умеет**: CLI-коннектор есть только у Claude Code. Поэтому запись заведена **неактивной**. Исполнитель на этой записи получит отказ «по CLI поддерживается только anthropic». Запись нужна, чтобы CLI можно было поставить и войти в него заранее.

## Установка и вход (ключ API не нужен)

1. Установить CLI: `npm install -g @xai-official/grok`.
2. Войти: `grok` — в терминале компьютера сервера, под пользователем, от имени которого работает AI2P.
3. Убедиться, что `grok` доступен из PATH этого пользователя; иначе впишите полный путь в поле `cliCommand`.

При первом запуске `grok` открывает браузер для входа. Без браузера — переменная окружения `XAI_API_KEY`.

Запуск без диалога (headless): `grok -p "..."`.

Кнопка с ключом в строке справочника моделей показывает команду входа этого CLI.
