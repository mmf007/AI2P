# Grok-4.7

**Размещение:** облако (API xAI, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://api.x.ai/v1`,
модель `grok-4.7`
**Ссылка на ключ:** `xai.apiKey`

xAI выпустил эту модель 21.09.2026; в справочник AI2P она занесена заданием
T-347-S0 — обходом производителей от 23.09.2026. Идентификатор `x-ai/grok-4.7`, длина
контекста, цена и модальности сверены запросом к публичному каталогу OpenRouter.

Продолжает линейку **Grok-4.6**: контекст 500 000 токенов, ответ до 64 000 токенов,
цена 1,60 $ и 4,80 $ за миллион токенов. Оценки навыков 89–93.

На вход принимает: текст и разметку Markdown, исходный код, изображения, PDF.

## Как получить ключ

1. Зарегистрируйтесь в [консоли xAI](https://console.x.ai/).
2. Заведите команду (team) и пополните баланс — без баланса запросы отклоняются.
3. Откройте **API Keys → Create API Key**, дайте имя и права на чат-модели.
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `xai-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → Grok-4.7 → «Установить ключ API»**.

Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ).

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 500 000 токенов |
| Максимум ответа | 64 000 токенов |
| Стоимость входа | 1,60 $ за 1 млн токенов |
| Стоимость выхода | 4,80 $ за 1 млн токенов |

**Идентификатор модели живым вызовом не проверен** — он взят из каталога моделей без
префикса вендора. Сверьте его запросом `GET /models` к `https://api.x.ai/v1`.
Актуальные цены — [xAI Pricing](https://x.ai/api).

Веса закрыты — речь о **результате генерации**.

По условиям для API xAI **не использует отправленное и полученное для обучения своих
моделей**. У потребительского Grok (сайт и приложение) условия другие: там данные идут на
обучение, а при использовании результата вместе с именем и знаками xAI требуется ссылка на
сервис. AI2P ходит по ключу API, поэтому действуют условия по ссылке выше.

Условия сверены по их тексту 23.09.2026.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.x.ai`.

## Частые ошибки

* **Счёт больше расчётного** — вероятно, задание перешло порог длины запроса, за
  которым у xAI действует повышенный тариф (для версии 4.7 он не опубликован).
  Держите историю чата короче или выносите материалы в файлы.
* **Модель «не знает» о недавнем событии** — граница знаний версии 4.7 xAI не
  объявлена; свежие сведения давайте прямо в задании.
* **403 / «no credits»** — не пополнен баланс команды xAI.
