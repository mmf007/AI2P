# Qwen3.6-27B-Local

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: openai-compatible`, `baseUrl: http://localhost:8082/v1`,
модель `qwen3.6-27b`
**Ключ API:** не нужен — локальный сервер поднимается без авторизации
**Что делает:** код и тексты, оценки навыков 75–82

Предыдущее поколение той же линейки: 27 млрд параметров, квант **UD-Q4_K_XL**, работает
через **llama.cpp / llama-server**. По качеству уступает
Qwen3.8-27B-Local (код 82 против 87) при тех же требованиях к
железу, поэтому держат её в основном ради совместимости: если задание уже проверено на
этой версии, менять модель под ним не обязательно. Платить не нужно, **данные не
покидают компьютер**.

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
ИИ-модели → Qwen3.6-27B-Local → «Установить»**. Ставятся:

* **пакет llama.cpp** (~0,5 ГБ) — сборка с `llama-server`, общий с другими локальными
  моделями: если он уже стоит, второй раз не качается;
* **файл весов** `Qwen3.6-27B-UD-Q4_K_XL.gguf` — **16,4 ГиБ** (17 612 564 704 байта)
  в репозиторий моделей (`storage.modelsRepo`, по умолчанию `C:\ai` на Windows и `~/ai`
  на Linux/macOS, группа `Qwen3.6`).

Качается с докачкой, скачанное сверяется по точному размеру. **Пока файлы не на месте,
модель активной быть не может** — это правило AI2P, а не ошибка.

Команда запуска, которая прописывается в профайл после установки:

```
llama-server.exe -m <путь к .gguf> -ngl 99 -c 65536 --jinja --port 8082 --alias qwen3.6-27b
```

Порт **8082** свой у этой записи (у соседних локальных моделей 8081 и 8083): два
`llama-server` на одном порту рядом не поднимутся, и вторая модель молча отвечала бы
ответами первой.

## Требования к железу

| | |
|---|---|
| Место на диске | **от 20 ГБ** на модель (веса + пакет llama.cpp) |
| Видеопамять | **24 ГБ** — вся модель на видеокарте |
| | **16 ГБ** — часть слоёв выгружается в ОЗУ, заметно медленнее |
| | **меньше 12 ГБ** — берите квант мельче (`UD-Q3_K_XL`) своей записью справочника |
| Оперативная память | **от 32 ГБ** |
| Процессор | чем больше ядер, тем быстрее в CPU-режиме |

Цифры — **оценка по размеру весов, замеров не делали**. Контекст в команде запуска —
65 536 токенов (`-c 65536`); чем он больше, тем больше видеопамяти уходит под KV-кэш.

**Первый запуск долгий:** загрузка весов занимает минуты — это не зависание.

## Частые ошибки

* **«N tokens exceeds context 32768»** — в команде запуска маленький `-c`; поставьте
  `-c 65536` и перезапустите работу команды.
* **Пустой результат, причина `length`** — мал `params.maxTokens`; поставьте 32768.
* **Обе модели Qwen отвечают одинаково** — совпали порты в командах запуска; у этой
  записи должен быть 8082.
* **Не хватает памяти** — закройте лишнее либо возьмите квант меньше.
