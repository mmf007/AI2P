# Claude-Sonnet-5_cli

**Размещение:** облако, но подключение **не по API, а по CLI**
**Подключение:** `provider: anthropic`, `transport: cli`, команда
`claude --permission-mode acceptEdits`, модель `claude-sonnet-5`
**Ссылка на ключ:** пусто — **ключ API не нужен**

Та же модель, что Claude-Sonnet-5, но запускается через **Claude Code
CLI** в headless-режиме. Платится не за токены, а **подпиской**, поэтому в биллинге AI2P
стоимость таких заданий равна нулю. Ниша — объёмная работа с файлами проекта, когда
платить за токены не хочется.

## Ключ API не нужен

Авторизация — сессией CLI, а не ключом. Поэтому в профайле `secretRef` пуст, и кнопки
«Установить ключ API» у этой модели нет.

Что нужно вместо ключа:

1. **Установить Claude Code** — [официальная инструкция](https://docs.claude.com/en/docs/claude-code/overview).
   Проверка: в консоли `claude --version` должен что-то напечатать.
2. **Войти под своей подпиской**: `claude login`. Сессия сохраняется в профиле
   пользователя ОС.
3. Убедиться, что `claude` доступен **из PATH того пользователя, под которым работает
   AI2P**. Если AI2P запущен службой от другой учётной записи, вход надо выполнить под ней.
4. Если исполняемый файл лежит не в PATH — пропишите полный путь в поле `cliCommand`
   профайла модели.

## Чем отличается от варианта по API

| | по API | по CLI |
|---|---|---|
| Оплата | по токенам | подпиской |
| Стоимость в биллинге | считается | 0 |
| Инструменты | инструменты AI2P | **штатные инструменты самого CLI** |
| Рабочий каталог | не важен | **папка проекта** |
| Вопросы человеку | штатно | по маркеру `AI2P_QUESTION` в ответе |
| Создание подзадач | инструментом `create_task` | по маркеру `AI2P_SUBTASK` |

Подробный разбор различий — в документе Claude-Fable-5_cli;
у Sonnet всё устроено ровно так же.

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 000 000 токенов |
| Максимум ответа | 128 000 токенов |
| Стоимость | 0 (оплачено подпиской) |

**Лимит подписки AI2P распознаёт и ждёт сброса** (правка v1.63): увидев отказ CLI с кодом
429, система берёт время сброса и переводит задачу в «ожидает» вместо «встал с ошибкой»,
а по сбросу **продолжает ту же сессию** (`--resume`), а не начинает задание заново.
Заполните у исполнителя-ИИ поля «лимит токенов за окно» и «окно лимита, ч» (у подписки
Claude окно — 5 часов), чтобы система предупреждала заранее.

настройках аккаунта Claude.

## Требования к железу

Никаких особых: считает провайдер. Нужен установленный Claude Code, выход в интернет и
место в каталоге проекта — агент работает с файлами напрямую.

## Частые ошибки

* **«claude не найден»** — CLI не установлен либо не в PATH пользователя AI2P.
* **Молчаливый отказ или запрос входа** — сессия создана под другой учётной записью ОС.
* **Агент не видит файлов задачи** — у проекта не задан каталог («Папка проекта»).
