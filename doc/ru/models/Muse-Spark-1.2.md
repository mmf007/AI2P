# Muse-Spark-1.2

**Размещение:** облако (Meta, **через шлюз OpenRouter**)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://openrouter.ai/api/v1`,
модель `meta/muse-spark-1.2`
**Ссылка на ключ:** `openrouter.apiKey`

Первая модель Meta уровня фронтира: оценки навыков 85–89, контекст 1 048 576 токенов,
цена 1,25 $ и 4,25 $ за миллион. Принимает на вход почти всё — текст, исходники, картинки,
PDF, звук и видео.

**Своего публичного OpenAI-совместимого входа у Meta нет**, поэтому запись подключена
через шлюз **OpenRouter**: запросы идут на `openrouter.ai`, а он передаёт их провайдеру.
Плата — по тарифу шлюза (сверху комиссия), зато ключ не нужен отдельный у Meta.

## Как получить ключ

**Ключ один на все модели через шлюз** — Inkling-975B,
Nemotron-3-Ultra, Ling-3.0-Flash и эта
ссылаются на один и тот же `openrouter.apiKey`. Ввели один раз — работают все четыре.

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/).
2. Пополните баланс: **Credits → Add credits** (карта или крипта). Без баланса
   доступны только бесплатные варианты моделей с очередью.
3. Откройте [openrouter.ai/keys](https://openrouter.ai/keys) → **Create key**, дайте имя
   и, если нужно, лимит расхода на ключ.
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `sk-or-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → Muse-Spark-1.2 → «Установить ключ API»**.

Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ).

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 048 576 токенов |
| Максимум ответа | 65 536 токенов |
| Стоимость входа | 1,25 $ за 1 млн токенов |
| Стоимость выхода | 4,25 $ за 1 млн токенов |

**Идентификатор модели живым вызовом не проверен.** У моделей через шлюз он приводится
**полным слагом с префиксом вендора** (`meta/muse-spark-1.2`) — без префикса шлюз ответит
404. Сверьте его запросом `GET /models` к `https://openrouter.ai/api/v1` (этот список
шлюз отдаёт и без ключа).

## Лицензия

| | |
|---|---|
| Условия на результат генерации | определяются **владельцем модели**, а не шлюзом: «Your ownership rights in the Output are set forth in the Model Terms for each Model you use» |
| Коммерческое использование | смотрите Model Terms на карточке модели у шлюза — шлюз отвечает за доставку, а не за права |
| Что обязательно | соблюдать условия и шлюза, и владельца модели; владелец вправе менять свои условия в любой момент |
| Текст условий | <https://openrouter.ai/terms> (редакция от 29.07.2026) плюс Model Terms на карточке модели |
| Плата за генерацию | по токенам — тариф в разделе «Ограничения и стоимость» |

Весов этой модели в открытом доступе нет (на HuggingFace репозиторий не найден, проверено
27.08.2026) — лицензировать нечего, действуют только условия владельца модели и шлюза.

Шлюз, со своей стороны, **по возможности отказывается от обучения на данных** у подключённых
провайдеров, но за точность чужих условий не отвечает и прямо это оговаривает.

Условия шлюза сверены по их тексту 27.08.2026.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `openrouter.ai`.

## Частые ошибки

* **404 «No endpoints found»** — в поле «модель» потерян префикс вендора либо у шлюза
  сменился слаг.
* **402 «Insufficient credits»** — не пополнен баланс OpenRouter.
* **Ответ пришёл дороже расчётного** — шлюз берёт свою комиссию сверх цены провайдера.
