# Qwen3.8-Max_cli

**Размещение:** облако, подключение **не по API, а по CLI**
**Подключение:** `provider: alibaba`, `transport: cli`, команда `qwen`, модель `qwen3.8-max`
**Ссылка на ключ:** пусто — **ключ API не нужен**, авторизация сессией CLI

Та же модель, что Qwen3.8-Max, но через терминальный агент вендора **Qwen Code** (https://github.com/QwenLM/qwen-code). Платится подпиской вендора, в биллинге AI2P стоимость таких заданий равна нулю.

## Важно: коннектора пока нет

Исполнять задания через Qwen Code AI2P **пока не умеет**: CLI-коннектор есть только у Claude Code. Поэтому запись заведена **неактивной**. Исполнитель на этой записи получит отказ «по CLI поддерживается только anthropic». Запись нужна, чтобы CLI можно было поставить и войти в него заранее.

## Установка и вход (ключ API не нужен)

1. Установить CLI: `npm i -g @qwen-code/qwen-code@latest`.
2. Войти: `qwen  →  /auth` — в терминале компьютера сервера, под пользователем, от имени которого работает AI2P.
3. Убедиться, что `qwen` доступен из PATH этого пользователя; иначе впишите полный путь в поле `cliCommand`.

Qwen Code — ответвление Gemini CLI от Alibaba. Вход: запустить `qwen` и выполнить `/auth` (Qwen OAuth или ключ API).

Запуск без диалога (headless): `qwen -p "..."`.

Кнопка с ключом в строке справочника моделей показывает команду входа этого CLI.
