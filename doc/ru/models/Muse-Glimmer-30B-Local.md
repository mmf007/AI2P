# Muse-Glimmer-30B-Local

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: openai-compatible`, `baseUrl: http://localhost:8083/v1`,
модель `muse-glimmer-30b`
**Ключ API:** не нужен — локальный сервер поднимается без авторизации
**Что делает:** тексты и код, оценки навыков 73–80

Открытая модель Meta на 30 млрд параметров в кванте **UD-Q4_K_XL**, работает через
**llama.cpp / llama-server**. Младшая родственница облачной
Muse-Spark-1.2. По коду слабее моделей Qwen того же размера
(75–78 против 82–87), зато ровнее в текстах — и, как все локальные записи, **бесплатна и
никуда не отправляет данные**.

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
ИИ-модели → Muse-Glimmer-30B-Local → «Установить»**. Ставятся:

* **пакет llama.cpp** (~0,5 ГБ) — сборка с `llama-server`, общий с другими локальными
  моделями;
* **файл весов** `Muse-Glimmer-30B-UD-Q4_K_XL.gguf` — **14,8 ГиБ** (15 878 222 368 байт)
  в репозиторий моделей (`storage.modelsRepo`, по умолчанию `C:\ai` на Windows и `~/ai`
  на Linux/macOS, группа `Muse-Glimmer`).

Это самый маленький файл среди локальных записей справочника, поэтому при нехватке
видеопамяти начинать проще с неё. Качается с докачкой, скачанное сверяется по точному
размеру. **Пока файлы не на месте, модель активной быть не может** — это правило AI2P,
а не ошибка.

Команда запуска, которая прописывается в профайл после установки:

```
llama-server.exe -m <путь к .gguf> -ngl 99 -c 65536 --jinja --port 8083 --alias muse-glimmer-30b
```

Порт **8083** свой у этой записи (у моделей Qwen — 8081 и 8082): два `llama-server` на
одном порту рядом не поднимутся.

## Требования к железу

| | |
|---|---|
| Место на диске | **от 20 ГБ** (веса 14,8 ГиБ + пакет llama.cpp) |
| Видеопамять | **24 ГБ** — вся модель на видеокарте, с запасом под контекст |
| | **16 ГБ** — помещается впритык либо с небольшой выгрузкой слоёв в ОЗУ |
| | **меньше 12 ГБ** — берите квант мельче (`UD-Q3_K_XL`) своей записью справочника |
| Оперативная память | **от 32 ГБ** |
| Процессор | чем больше ядер, тем быстрее в CPU-режиме |

Цифры — **оценка по размеру весов, замеров не делали**: модель на этом компьютере не
запускалась. Контекст в команде запуска — 65 536 токенов (`-c 65536`); чем он больше,
тем больше видеопамяти уходит под KV-кэш.

**Первый запуск долгий:** загрузка весов занимает минуты — это не зависание.

## Частые ошибки

* **«N tokens exceeds context 32768»** — в команде запуска маленький `-c`; поставьте
  `-c 65536` и перезапустите работу команды.
* **Пустой результат, причина `length`** — мал `params.maxTokens`; поставьте 32768.
* **Порт 8083 занят** — поменяйте `--port` в команде запуска и `baseUrl` в профайле.
* **Не хватает памяти** — возьмите квант меньше либо освободите видеопамять.
