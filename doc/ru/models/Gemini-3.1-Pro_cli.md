# Gemini-3.1-Pro_cli

**Размещение:** облако, подключение **не по API, а по CLI**
**Подключение:** `provider: google`, `transport: cli`, команда `agy`, модель `gemini-3.1-pro`
**Ссылка на ключ:** пусто — **ключ API не нужен**, авторизация сессией CLI

Та же модель, что Gemini-3.1-Pro, но через терминальный агент вендора **Google Antigravity CLI** (https://antigravity.google). Платится подпиской вендора, в биллинге AI2P стоимость таких заданий равна нулю.

## Важно: коннектора пока нет

Исполнять задания через Google Antigravity CLI AI2P **пока не умеет**: CLI-коннектор есть только у Claude Code. Поэтому запись заведена **неактивной**. Исполнитель на этой записи получит отказ «по CLI поддерживается только anthropic». Запись нужна, чтобы CLI можно было поставить и войти в него заранее.

## Установка и вход (ключ API не нужен)

1. Установить CLI: `irm https://antigravity.google/cli/install.ps1 | iex`.
2. Войти: `agy` — в терминале компьютера сервера, под пользователем, от имени которого работает AI2P.
3. Убедиться, что `agy` доступен из PATH этого пользователя; иначе впишите полный путь в поле `cliCommand`.

Antigravity CLI заменил Gemini CLI 18.06.2026. При первом запуске `agy` печатает ссылку и одноразовый код: откройте ссылку, войдите в аккаунт Google и вставьте код.

Запуск без диалога (headless): `agy -p "..."`.

Кнопка с ключом в строке справочника моделей показывает команду входа этого CLI.
