# YandexGPT-5.1-Pro

**Размещение:** облако (Yandex Cloud, Россия; OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`,
`baseUrl: https://llm.api.cloud.yandex.net/v1`, модель
`gpt://<folder-id>/yandexgpt/latest`
**Ссылка на ключ:** `yandex.apiKey`

Сильный русский текст: `text-write` 86, `text-translate` 86, `text-edit` 85. Код —
слабое место (60–64), на программирование эту модель брать не стоит. Контекст скромный
по меркам справочника: 32 000 токенов.

## В поле «модель» надо подставить свой адрес

Yandex Cloud ждёт не короткий идентификатор, а **полный ресурс**:

```
gpt://<folder-id>/yandexgpt/latest
```

**Идентификатор каталога (folder ID) свой у каждого пользователя**, поэтому в справочнике
он оставлен заглушкой — запись «из коробки» работать не будет. Откройте
**Настройки → Справочники → ИИ-модели → YandexGPT-5.1-Pro → «Профайл подключения»** и
замените `<folder-id>` на свой (вида `b1g...`, виден в консоли Yandex Cloud
в адресе каталога). Вместо `latest` можно указать конкретную версию модели.

## Как получить ключ

1. Заведите каталог в [консоли Yandex Cloud](https://console.yandex.cloud/) и подключите
   к платёжному аккаунту.
2. Создайте **сервисный аккаунт** и выдайте ему роль `ai.languageModels.user` на каталог.
3. Создайте **API-ключ** сервисного аккаунта: **Сервисные аккаунты → ваш аккаунт →
   Создать новый ключ → Создать API-ключ**.
4. Скопируйте секретную часть — она показывается **один раз**.
5. Скопируйте **идентификатор каталога** и подставьте его в поле «модель» профайла
   (см. выше).
6. В AI2P: **Настройки → Справочники → ИИ-модели → YandexGPT-5.1-Pro →
   «Установить ключ API»**.

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 32 000 токенов |
| Максимум ответа | 16 000 токенов |
| Стоимость | по тарифу Yandex Cloud (в справочнике проставлен ноль) |

Тариф считается в рублях за тысячу токенов, поэтому в декларации стоимость оставлена
нулевой — **расход по этой модели биллинг AI2P не покажет**; смотрите его в консоли
Yandex Cloud. Контекст 32 000 токенов — самый маленький в справочнике: длинное описание
задачи или большая история чата в него не поместятся.

**Идентификатор модели живым вызовом не проверен** — сверьте список доступных моделей
запросом `GET /models` к `https://llm.api.cloud.yandex.net/v1` со своим ключом.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к
`llm.api.cloud.yandex.net`.

## Частые ошибки

* **400 / «model not found»** — в поле «модель» осталась заглушка
  `<folder-id>`.
* **403 «permission denied»** — сервисному аккаунту не выдана роль
  `ai.languageModels.user` на нужный каталог.
* **Задание обрывается на длинном описании** — не хватает 32 000 токенов контекста;
  выносите материалы в файлы, а в описание давайте ссылки.
