# Mistral-Large-3_cli

**Размещение:** облако, подключение **не по API, а по CLI**
**Подключение:** `provider: mistral`, `transport: cli`, команда `vibe`, модель `mistral-large-3`
**Ссылка на ключ:** пусто — **ключ API не нужен**, авторизация сессией CLI

Та же модель, что Mistral-Large-3, но через терминальный агент вендора **Mistral Vibe CLI** (https://github.com/mistralai/mistral-vibe). Платится подпиской вендора, в биллинге AI2P стоимость таких заданий равна нулю.

## Важно: коннектора пока нет

Исполнять задания через Mistral Vibe CLI AI2P **пока не умеет**: CLI-коннектор есть только у Claude Code. Поэтому запись заведена **неактивной**. Исполнитель на этой записи получит отказ «по CLI поддерживается только anthropic». Запись нужна, чтобы CLI можно было поставить и войти в него заранее.

## Установка и вход (ключ API не нужен)

1. Установить CLI: `curl -LsSf https://mistral.ai/vibe/install.sh | bash   (pip install mistral-vibe)`.
2. Войти: `vibe` — в терминале компьютера сервера, под пользователем, от имени которого работает AI2P.
3. Убедиться, что `vibe` доступен из PATH этого пользователя; иначе впишите полный путь в поле `cliCommand`.

При первом запуске `vibe` открывает мастер настройки: вход аккаунтом Mistral или ключ API. По умолчанию Vibe работает на Devstral — модель записи задаётся полем «модель».

Ключ запуска без диалога (headless) по открытым источникам не подтверждён — уточните в документации CLI.

Кнопка с ключом в строке справочника моделей показывает команду входа этого CLI.
