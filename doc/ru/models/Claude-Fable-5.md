# Claude-Fable-5

**Размещение:** облако (API провайдера Anthropic)
**Подключение:** `provider: anthropic`, модель `claude-fable-5`
**Ссылка на ключ:** `anthropic.apiKey`

Самая сильная из подключённых моделей: код, тексты, анализ требований и планирование.
Ею разумно ставить головные задачи процесса и разбор требований, а рутину отдавать более
дешёвым моделям — соотношение «цена ↔ качество» настраивается в проекте.

## Как получить ключ

1. Зарегистрируйтесь в [Anthropic Console](https://console.anthropic.com/).
2. Пополните баланс: **Plan & Billing → Add credits**. Без положительного баланса ключ
   создаётся, но запросы отклоняются с ошибкой о недостатке средств.
3. Откройте **Settings → API keys → Create Key**, дайте ключу понятное имя
   (например `AI2P-рабочий`).
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `sk-ant-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → Claude-Fable-5 → «Установить ключ API»**.
   Значение вводится в поле-пароль и больше нигде не показывается.

Ключ принадлежит **организации**: он шифруется ключом организации и реплицируется на все
её серверы, поэтому вводить его на каждом сервере не нужно. Подробности — гл. 10 ТЗ.

Как только ключ установлен, модель становится активной. Без ключа облачная модель активной
быть не может.

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 000 000 токенов |
| Максимум ответа | 128 000 токенов |
| Стоимость входа | 10,00 $ за 1 млн токенов |
| Стоимость выхода | 50,00 $ за 1 млн токенов |

Стоимость каждого задания считается по этим числам и попадает в биллинг (ТЗ п. 6.2-бис).
Актуальные цены смотрите на странице [Anthropic Pricing](https://www.anthropic.com/pricing) —
если они изменились, поправьте `cost` в декларации возможностей модели.

**Идентификатор модели живым вызовом не проверен.** Перед первым заданием сверьте его
запросом `GET /models` к API провайдера: у Anthropic названия чекпойнтов меняются, и
неверный id даёт 404 уже на исполнителе.

not train models on Customer Content from Services»). У варианта той же модели по подписке
(запись с суффиксом `_cli`) условия ДРУГИЕ — там действуют потребительские, и обучение на
материалах идёт, пока вы не откажетесь в настройках аккаунта.

## Требования к железу

Никаких: вычисления идут на стороне провайдера. Нужен только выход в интернет к
`api.anthropic.com`.

## Частые ошибки

* **«Ключ API не найден»** — ключ не введён либо этот сервер ещё не получил ключ
  организации (он выдаётся при подтверждении подключения сервера к организации).
* **401 от провайдера** — ключ отозван или скопирован не полностью.
* **«37529 tokens exceeds context»** — задача с огромным описанием; уменьшите вход либо
  поднимите `params.maxTokens` в профайле.
* **Отказ классификаторов безопасности** — в профайле задана подстраховка
  `params.fallbacks: ["claude-opus-5"]`: запрос автоматически повторяется другой моделью.

## Альтернатива без ключа

Есть вариант того же семейства с подключением по CLI — **Claude-Fable-5_cli**: он работает
через подписку Claude Code и ключа API не требует. Смотрите его документ.
