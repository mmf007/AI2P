# Claude-Opus-5.5

**Размещение:** облако (API провайдера Anthropic)
**Подключение:** `provider: anthropic`, модель `claude-opus-5-5`
**Ссылка на ключ:** `anthropic.apiKey`

Anthropic выпустил эту модель 22.09.2026; в справочник AI2P она занесена заданием
T-347-S0 — обходом производителей от 23.09.2026. Идентификатор `anthropic/claude-opus-5.5`, длина
контекста, цена и модальности сверены запросом к публичному каталогу OpenRouter.

Продолжает линейку **Claude-Opus-5.0**: контекст 1 000 000 токенов, ответ до 128 000 токенов,
цена 4,00 $ и 20,00 $ за миллион токенов. Оценки навыков 93–98.

На вход принимает: текст и разметку Markdown, исходный код, изображения, PDF.

## Как получить ключ

**Ключ тот же самый**, что у Claude-Fable-5 — обе модели ходят к одному провайдеру и
ссылаются на один секрет `anthropic.apiKey`. Если ключ уже введён для одной из них, вторая
заработает сама.

Если ключа ещё нет:

1. Зарегистрируйтесь в [Anthropic Console](https://console.anthropic.com/).
2. Пополните баланс: **Plan & Billing → Add credits**.
3. **Settings → API keys → Create Key**, скопируйте значение (показывается один раз,
   начинается с `sk-ant-`).
4. В AI2P: **Настройки → Справочники → ИИ-модели → Claude-Opus-5.5 → «Установить ключ API»**.

Ключ принадлежит организации и реплицируется на её серверы зашифрованным (гл. 10 ТЗ).

**Идентификатор модели живым вызовом не проверен.** Перед первым заданием сверьте его
запросом `GET /models` к API провайдера: у Anthropic названия чекпойнтов меняются, и
неверный id даёт 404 уже на исполнителе.

По этим же условиям Anthropic **не обучает модели на том, что уходит в API** («Anthropic may
not train models on Customer Content from Services»). У варианта той же модели по подписке
(запись с суффиксом `_cli`) условия ДРУГИЕ — там действуют потребительские, и обучение на
материалах идёт, пока вы не откажетесь в настройках аккаунта.

Условия сверены по их тексту 23.09.2026; провайдер вправе их менять — перед коммерческим
выпуском откройте ссылку ещё раз.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.anthropic.com`.

## Когда какую из двух брать

* **Claude-Fable-5** — головные задачи процесса, разбор требований, планирование, сложный код.
* **Claude-Opus-5.5** — всё остальное: правки, документация, переводы, ревью.

Выбор можно не делать руками: у проекта есть ползунок **цена ↔ качество**, и автоподбор
исполнителя учитывает и оценки навыков модели, и её стоимость (ТЗ п. 2.7).

## Альтернатива без ключа

**Claude-Opus-5.0_cli** — та же модель через Claude Code CLI по подписке, без ключа API.
