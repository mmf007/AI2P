# Qwen3.6-35B-A3B-Local

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: openai-compatible`, `baseUrl: http://localhost:8080/v1`
**Ключ API:** не нужен — локальный сервер поднимается без авторизации
**Что делает:** код и тексты, оценки навыков 72–80

Текстовая модель Qwen 3.6 (35 млрд параметров, MoE с 3 млрд активных) в кванте
**Q4_K_M**, работает через **llama.cpp / llama-server**. Качество ниже облачных моделей,
зато **бесплатно и никуда не уходит**: данные не покидают компьютер. Разумный выбор для
задач, которые нельзя отдавать в облако.

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
ИИ-модели → Qwen3.6-35B-A3B-Local → «Установить»**. Ставятся:

* **пакет llama.cpp** (~640 МБ) — сборка с `llama-server`;
* **файл весов** `Qwen3.6-35B-A3B-UD-Q4_K_M.gguf` — **~20,6 ГиБ** в репозиторий моделей
  (`storage.modelsRepo`, по умолчанию `C:\ai` на Windows и `~/ai` на Linux/macOS,
  группа `Qwen3.6`).

Качается с докачкой: прерванная установка продолжается, уже скачанное не перекачивается.
Пока файлы не на месте, модель активной быть не может.

После установки в профайл автоматически прописывается команда запуска:

```
llama-server.exe -m <путь к .gguf> --n-cpu-moe 99 -ngl 99 -c 65536 --jinja
                 --port 8080 --alias qwen3.6-35b-a3b
```

AI2P сам поднимает этот процесс при старте работы команды и выгружает при остановке —
**именно свой процесс**; уже работающий чужой llama-server на 8080 не трогается.

## Требования к железу

| | |
|---|---|
| Место на диске | **~22 ГБ** (веса + пакет) |
| Оперативная память | **минимум 24 ГБ**, комфортно 32 ГБ |
| Видеокарта | не обязательна, но сильно ускоряет |
| VRAM | от 6 ГБ даёт заметный выигрыш; ключ `--n-cpu-moe 99` держит эксперты в RAM, а на GPU уходит остальное |
| Процессор | чем больше ядер, тем быстрее на CPU-режиме |

Модель **MoE**: при 35 млрд параметров активны около 3 млрд, поэтому она заметно быстрее
плотной модели того же размера. Но в память грузится целиком — 20,6 ГиБ весов должны
куда-то поместиться.

**Первый запуск долгий:** загрузка весов занимает минуты. AI2P ждёт готовности API и
показывает участника команды в состоянии «запускается» — это не зависание.

## Контекст и максимум ответа

| | |
|---|---|
| Контекст | 65 536 токенов (`-c 65536` в команде запуска) |
| Максимум ответа | 32 768 токенов (`params.maxTokens`) |

Эта связка проверена и важна: при **меньшем** контексте ответы обрывались по причине
`length` — модель сжигала лимит на рассуждения и возвращала пустой результат. Если
правите одно число, правьте и второе.

## Частые ошибки

* **«37529 tokens exceeds context 32768»** — в команде запуска стоит маленький `-c`.
  Поставьте `-c 65536` в поле «Команда запуска» профайла и перезапустите работу команды.
* **Пустой результат, причина `length`** — мал `params.maxTokens`; поставьте 32768.
* **Не хватает памяти / система уходит в своп** — модели нужно порядка 24 ГБ RAM;
  закройте лишнее либо возьмите квант меньше (тогда придётся завести свою запись
  справочника со своим манифестом).
* **Порт 8080 занят** — поменяйте `--port` в команде запуска и `baseUrl` в профайле.

## Устаревший способ установки

Скрипты `install_local_model.bat/.ps1/.sh` в каталоге приложения ставят ту же модель
без UI (для офлайн-сценариев). Они создают **отдельную кастомную запись** справочника —
не путайте её со встроенной. Начиная с версии 1.42 штатный способ — кнопка «Установить».
