# GPT-5.6-Sol

**Размещение:** облако (API OpenAI, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://api.openai.com/v1`,
модель `gpt-5.6-sol`
**Ссылка на ключ:** `openai.apiKey`

Флагман OpenAI и самая сильная запись справочника по оценкам навыков (91–95): код,
разбор требований и планирование — 93–94 из 100. Цена соответствующая: 5 $ и 30 $ за
миллион токенов, дороже всех остальных текстовых моделей справочника. Берите на то,
что действительно требует лучшего результата; объёмную рутину дешевле отдать
GPT-5.6-Terra или DeepSeek-V4-Pro.

У OpenAI для этой модели есть ограниченное превью тарифа **Ultrafast** (до 14 раз быстрее);
в справочнике он не заведён — при необходимости заведите свою запись со своим id.

## Как получить ключ

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com/).
2. Пополните баланс: **Settings → Billing → Add to credit balance**. Без баланса
   запросы отклоняются с 429.
3. Откройте [platform.openai.com/api-keys](https://platform.openai.com/api-keys) →
   **Create new secret key**, дайте имя.
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `sk-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → GPT-5.6-Sol → «Установить ключ API»**.

Ключ общий с GPT-5.6-Terra — обе модели ссылаются на `openai.apiKey`.
Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ).

| Коммерческое использование | разрешено |
| Что обязательно | соблюдать Usage Policies; помнить, что уникальности результата вам не обещают — тот же ответ может достаться другому |
| Текст условий | <https://openai.com/policies/services-agreement/> |
| Плата за генерацию | по токенам — тариф в разделе «Ограничения и стоимость» |

Веса закрыты, лицензировать нечего — условия относятся к **результату генерации**.

Содержимое, уходящее в API, OpenAI **не использует для развития своих сервисов**, пока вы
явно этого не разрешили; у потребительского ChatGPT это не так.

Сверено 27.08.2026: формулировка о владении результатом («you … own the Output. We hereby
assign to you all our right, title, and interest, if any, in and to Output») прочитана в
условиях OpenAI дословно; та же формулировка стоит в соглашении для API по ссылке выше.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.openai.com`.

## Частые ошибки

* **404 «model not found»** — id сменился; сверьте списком `GET /models`.
* **429 «insufficient_quota»** — не пополнен баланс либо исчерпан лимит организации.
* **Ответ пустой, причина `length`** — модель израсходовала лимит ответа на рассуждения;
  увеличьте `params.maxTokens` в профайле (по умолчанию 32000).
