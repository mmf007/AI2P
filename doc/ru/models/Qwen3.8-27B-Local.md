# Qwen3.8-27B-Local

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: openai-compatible`, `baseUrl: http://localhost:8081/v1`,
модель `qwen3.8-27b`
**Ключ API:** не нужен — локальный сервер поднимается без авторизации
**Что делает:** код и тексты, оценки навыков 80–87

Лучший вариант «на одну видеокарту» в справочнике: 27 млрд параметров, квант
**UD-Q4_K_XL**, работает через **llama.cpp / llama-server**. По коду (оценка 87) обгоняет
Qwen3.6-27B-Local и Muse-Glimmer-30B-Local,
а платить не нужно вовсе: **данные не покидают компьютер**. Разумный выбор для задач,
которые нельзя отдавать в облако.

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
ИИ-модели → Qwen3.8-27B-Local → «Установить»**. Ставятся:

* **пакет llama.cpp** (~0,5 ГБ) — сборка с `llama-server`;
* **файл весов** `Qwen3.8-27B-UD-Q4_K_XL.gguf` — **16,7 ГиБ** (17 923 394 624 байта)
  в репозиторий моделей (`storage.modelsRepo`, по умолчанию `C:\ai` на Windows и `~/ai`
  на Linux/macOS, группа `Qwen3.8`).

Качается с докачкой: прерванная установка продолжается, уже скачанное не перекачивается,
скачанное сверяется по точному размеру. **Пока файлы не на месте, модель активной быть
не может** — это правило AI2P, а не ошибка.

После установки в профайл прописывается команда запуска:

```
llama-server.exe -m <путь к .gguf> -ngl 99 -c 65536 --jinja --port 8081 --alias qwen3.8-27b
```

Порт **8081** свой у этой записи: у соседних локальных моделей 8082 и 8083, иначе второй
`llama-server` не поднялся бы рядом с первым. AI2P сам запускает этот процесс при старте
работы команды и выгружает при остановке — **именно свой процесс**; чужой llama-server
на том же порту не трогается.

## Требования к железу

| | |
|---|---|
| Место на диске | **от 20 ГБ** на модель (веса + пакет llama.cpp) |
| Видеопамять | **24 ГБ** — вся модель на видеокарте (RTX 3090/4090/5090) |
| | **16 ГБ** — часть слоёв выгружается в ОЗУ, заметно медленнее |
| | **меньше 12 ГБ** — берите квант мельче (`UD-Q3_K_XL`) своей записью справочника |
| Оперативная память | **от 32 ГБ** |
| Процессор | чем больше ядер, тем быстрее в CPU-режиме |

Цифры — **оценка по размеру весов, замеров не делали**: модель на этом компьютере не
запускалась. Контекст в команде запуска — 65 536 токенов (`-c 65536`); чем он больше,
тем больше видеопамяти уходит под KV-кэш.

**Первый запуск долгий:** загрузка весов занимает минуты. AI2P ждёт готовности API и
показывает участника команды в состоянии «запускается» — это не зависание.

## Частые ошибки

* **«N tokens exceeds context 32768»** — в команде запуска маленький `-c`; поставьте
  `-c 65536` и перезапустите работу команды.
* **Пустой результат, причина `length`** — мал `params.maxTokens`; поставьте 32768.
* **Не хватает памяти / система уходит в своп** — закройте лишнее либо возьмите квант
  меньше.
* **Порт 8081 занят** — поменяйте `--port` в команде запуска и `baseUrl` в профайле.
