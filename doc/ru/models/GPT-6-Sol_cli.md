# GPT-6-Sol_cli

**Размещение:** облако, подключение **не по API, а по CLI**
**Подключение:** `provider: openai`, `transport: cli`, команда `codex`, модель `gpt-6-sol`
**Ссылка на ключ:** пусто — **ключ API не нужен**, авторизация сессией CLI

Та же модель, что GPT-6-Sol, но через терминальный агент вендора **OpenAI Codex CLI** (https://github.com/openai/codex). Платится подпиской вендора, в биллинге AI2P стоимость таких заданий равна нулю.

## Важно: коннектора пока нет

Исполнять задания через OpenAI Codex CLI AI2P **пока не умеет**: CLI-коннектор есть только у Claude Code. Поэтому запись заведена **неактивной**. Исполнитель на этой записи получит отказ «по CLI поддерживается только anthropic». Запись нужна, чтобы CLI можно было поставить и войти в него заранее.

## Установка и вход (ключ API не нужен)

1. Установить CLI: `npm i -g @openai/codex`.
2. Войти: `codex login` — в терминале компьютера сервера, под пользователем, от имени которого работает AI2P.
3. Убедиться, что `codex` доступен из PATH этого пользователя; иначе впишите полный путь в поле `cliCommand`.

Вход — подпиской ChatGPT (Plus, Pro, Team, Enterprise) либо ключом API OpenAI.

Запуск без диалога (headless): `codex exec "..."`.

Кнопка с ключом в строке справочника моделей показывает команду входа этого CLI.
