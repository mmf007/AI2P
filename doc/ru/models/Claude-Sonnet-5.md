# Claude-Sonnet-5

**Размещение:** облако (API Anthropic)
**Подключение:** `provider: anthropic`, модель `claude-sonnet-5`
**Ссылка на ключ:** `anthropic.apiKey`

Рабочая лошадка линейки Claude 5: качество близко к Claude-Opus-5.0
(оценки навыков 89–93 против 95–98), а цена вдвое ниже и **постоянна** — 2 $ за 1 млн
входных токенов и 10 $ за 1 млн выходных, без скидок за время суток. Разумный выбор,
когда Opus избыточен, а Claude-Haiku-4.5 уже не тянет.

## Как получить ключ

1. Заведите организацию на [console.anthropic.com](https://console.anthropic.com/).
2. Пополните баланс: **Billing → Add credits**. Без баланса запросы отклоняются.
3. Откройте **API keys → Create Key**, дайте имя.
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `sk-ant-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → Claude-Sonnet-5 → «Установить ключ API»**.

Ключ общий со всеми моделями Anthropic — Claude-Fable-5,
Claude-Opus-5.0, Claude-Haiku-4.5: все они
ссылаются на `anthropic.apiKey`. Ввели один раз — работают все.

Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ).

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 000 000 токенов |
| Максимум ответа | 128 000 токенов |
| Стоимость входа | 2,00 $ за 1 млн токенов |
| Стоимость выхода | 10,00 $ за 1 млн токенов |

В профайле стоит `params.maxTokens: 16000` и `effort: high` — это ограничение **одного
ответа**, а не контекста; поднимайте, если результат обрывается с причиной `length`.

**Идентификатор модели живым вызовом не проверен.** Перед первым заданием сверьте его
запросом `GET /models` к API провайдера: у Anthropic названия чекпойнтов меняются, и
неверный id даёт 404 уже на исполнителе. Актуальные цены —
[Anthropic Pricing](https://www.anthropic.com/pricing).

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.anthropic.com`.

## Частые ошибки

* **401 / «invalid x-api-key»** — ключ введён с пробелом или обрезан.
* **400 «credit balance is too low»** — не пополнен баланс организации Anthropic.
* **Ответ пустой, причина `length`** — мал `params.maxTokens` в профайле модели.
* **Задание идёт дороже ожидаемого** — считайте по обоим числам: длинная история чата
  уезжает во вход при каждом ходе агента.
