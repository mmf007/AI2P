# TripoSplat

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: comfyui`, `baseUrl: http://127.0.0.1:8188`, модель `triposplat`
**Ключ API:** не нужен — сервер поднимается локально без авторизации
**Что делает:** изображение → ГАУССОВЫ СПЛАТЫ, навык `3d-image` 80

Открытая модель Tripo AI (VAST-AI), превращающая ОДНУ картинку не в сетку, а в облако
трёхмерных гауссиан — **гауссовы сплаты**. Единственная запись справочника, дающая такой
результат: файл `.spz`, который открывают просмотрщики сплатов, Unreal, Unity и веб-плееры
вроде Babylon.js.

Сплаты — это НЕ сетка: полигонов и UV в них нет, поэтому в игровой конвейер их кладут
как есть или конвертируют отдельно. Зато они дают фотографичную картинку с мягкими краями
и прозрачностью там, где сетка выглядит грубо (растительность, мех, дым, интерьеры).

Работает через **ComfyUI**: AI2P поднимает его как локальный сервер, отправляет workflow
и забирает готовый `.spz` в артефакты задачи.

**Читается КАРТИНКА, а не текст.** В графе модели нет текстового энкодера вовсе — условие
даёт DINOv3 по стартовому кадру. Описание задачи модель не видит: что нарисовано на
картинке, то и получится. Стартовый кадр задаётся в описании задачи ссылкой на объект
проекта (`@obj:OBJ-3`) либо путём файла относительно папки проекта; без него задание не
запустится вовсе.

Фон со стартового кадра снимается автоматически (BiRefNet).

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
Модели → TripoSplat → «Установить»**. Ставятся:

* **пакет ComfyUI** (~2,1 ГБ) — портативная сборка с собственным Python;
* **пять файлов весов** в репозиторий моделей (`storage.modelsRepo`), группа `TripoSplat`:

| Файл | Размер | Куда |
|---|---|---|
| `dino_v3_vit_h.safetensors` | ~1,57 ГиБ | `clip_vision` |
| `triposplat_fp16.safetensors` | ~707 МиБ | `diffusion_models` |
| `triposplat_vae_decoder_fp16.safetensors` | ~549 МиБ | `vae` |
| `flux2-vae.safetensors` | ~321 МиБ | `vae` |
| `birefnet.safetensors` | ~424 МиБ | `background_removal` |

**Итого около 3,8 ГБ загрузки** — самая лёгкая из локальных 3D-записей справочника.
Качается с докачкой: прерванная установка продолжится с того места, где остановилась,
уже скачанные файлы не перекачиваются.

Пока файлы не на месте, модель **не может быть активной** — это проверяется и при старте
приложения.

## Требования к железу

| | |
|---|---|
| Видеокарта | NVIDIA, **от 8 ГБ VRAM** (12 ГБ комфортно) |
| Драйвер NVIDIA | **580 или новее** — на старом драйвере torch падает без сообщения |
| Место на диске | ~6 ГБ (веса + пакет ComfyUI) |
| Оперативная память | от 16 ГБ |
| ОС | Windows (портативная сборка ComfyUI); на Linux ComfyUI ставится руками |

Цифра по видеопамяти — **оценка**, а не замер. Не хватило памяти — уменьшайте
`num_gaussians` у `VAEDecodeTripoSplat` в шаблоне workflow (по умолчанию 262144).

## Сколько ждать

Единицы минут на модель на современной карте: сама модель маленькая (около 700 МБ весов),
и ступень одна, а не четыре, как у TRELLIS-2. Таймаут задания в профайле выставлен в
60 минут (`params.timeoutMinutes`).

Ход генерации виден в **консоли задания** в карточке задачи: туда льётся собственный
вывод ComfyUI вместе с его прогресс-баром.

## Параметры генерации

Правятся в профайле модели (кнопка «Профайл подключения»):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `steps` | 20 | шагов диффузии |
| `timeoutMinutes` | 60 | сколько ждать результат |
| `width` / `height` | 1024 | на результат НЕ влияют: у 3D нет кадра |
| `negative` | пусто | не действует — текстового энкодера в графе нет |

Число гауссиан (`num_gaussians`, 262144) и формат файла (`spz`) задаются шаблоном
workflow. Форматы, которые умеет узел `SplatToFile3D`, — `spz`, `ply`, `splat`, `ksplat`;
`spz` выбран как самый компактный.

**Чего в шаблоне намеренно нет.** Официальный шаблон ComfyUI дополнительно рисует оборот
камеры вокруг объекта и сохраняет его роликом (`RenderSplat` → `CreateVideo` →
`SaveVideo`). Мы эту ветку не перенесли: это отдельный рендер на каждую генерацию, а
результатом задания и так является файл сплатов. Там же лежит `SplatToMesh` — узел,
превращающий сплаты в обычную сетку; кому нужна сетка, тот дописывает его в свой
workflow либо берёт [TRELLIS-2](https://huggingface.co/microsoft/TRELLIS.2-4B).

## Обучение LoRA

**Не поддерживается, и это честный отказ, а не недоделка.** Публичного тренера LoRA для
3D-архитектур сегодня нет: [musubi-tuner](https://github.com/kohya-ss/musubi-tuner), на
котором держится всё обучение адаптеров в AI2P, умеет только картинки и видео. Поэтому в
профайле стоит `lora.supported: false`, и форма модели показывает причину словами.

Постоянство объекта между кадрами достигается здесь другим способом: одну и ту же
эталонную картинку персонажа (объект проекта, ссылка `@obj:`) подавайте на вход — от
одинаковой картинки и одинакового `seed` выйдет одинаковый результат.

## Частые ошибки

* **«Модель не установлена»** — файлы не докачаны; откройте «Установить», окно покажет
  оставшийся объём.
* **Задание отказывается стартовать без картинки** — так и задумано: модель работает
  только от изображения. Дайте ссылку `@obj:` на эталонный кадр или путь файла.
* **Файл `.spz` не открывается привычной программой** — это сплаты, а не сетка; нужен
  просмотрщик гауссовых сплатов либо конвертация.
* **Нехватка VRAM** — уменьшите `num_gaussians` в шаблоне workflow.
* **Процесс исчезает без сообщения** — почти всегда старый драйвер NVIDIA (см. выше).
