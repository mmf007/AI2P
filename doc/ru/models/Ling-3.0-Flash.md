# Ling-3.0-Flash

**Размещение:** облако (Ant Group, **через шлюз OpenRouter**)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://openrouter.ai/api/v1`,
модель `inclusionai/ling-3.0-flash`
**Ссылка на ключ:** `openrouter.apiKey`

**Самая дешёвая запись справочника: 0,021 $ за 1 млн входных токенов** — примерно в
полтораста раз дешевле Kimi-K3. Модель на 124 млрд параметров (5,1 млрд
активных), целится в высокочастотные агентные сценарии: много коротких ходов подряд.

Ниша в AI2P — **дешёвый фон** для многоходовых заданий: черновики, массовые мелкие
правки, предварительная разметка материала. Оценки навыков 74–82, и контекст здесь
меньше, чем у соседей, — 262 144 токена.

Своего публичного API у Ant Group нет, поэтому запись идёт через шлюз **OpenRouter**.

## Как получить ключ

**Ключ один на все модели через шлюз** — Muse-Spark-1.2,
Inkling-975B, Nemotron-3-Ultra и эта
ссылаются на один и тот же `openrouter.apiKey`.

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/).
2. Пополните баланс: **Credits → Add credits**. Минимального пополнения хватит надолго:
   миллион входных токенов стоит две копейки.
3. Откройте [openrouter.ai/keys](https://openrouter.ai/keys) → **Create key**.
4. Скопируйте значение (показывается один раз, начинается с `sk-or-`).
5. В AI2P: **Настройки → Справочники → ИИ-модели → Ling-3.0-Flash → «Установить ключ API»**.

**Идентификатор модели живым вызовом не проверен.** У моделей через шлюз он приводится
полным слагом с префиксом вендора (`inclusionai/ling-3.0-flash`). Сверьте его запросом
`GET /models` к `https://openrouter.ai/api/v1`.

| | |
|---|---|
| Условия на результат генерации | определяются **владельцем модели**, а не шлюзом: «Your ownership rights in the Output are set forth in the Model Terms for each Model you use» |
| Коммерческое использование | смотрите Model Terms на карточке модели у шлюза — шлюз отвечает за доставку, а не за права |
| Что обязательно | соблюдать условия и шлюза, и владельца модели; владелец вправе менять свои условия в любой момент |
| Текст условий | <https://openrouter.ai/terms> (редакция от 29.07.2026) плюс Model Terms на карточке модели |
| Плата за генерацию | по токенам — тариф в разделе «Ограничения и стоимость» |

Веса этой модели тоже открыты: **MIT** (карточка `inclusionAI/Ling-3.0-flash`, сверено
27.08.2026) — коммерческое использование разрешено, требуется сохранить текст лицензии и
уведомление об авторских правах. То есть модель можно поднять и у себя; запись справочника
ходит через шлюз, и на результат распространяются условия владельца модели.

Шлюз, со своей стороны, **по возможности отказывается от обучения на данных** у подключённых
провайдеров, но за точность чужих условий не отвечает и прямо это оговаривает.

Условия шлюза сверены по их тексту 27.08.2026.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `openrouter.ai`.

## Частые ошибки

* **Автоподбор всё время выбирает именно её** — ползунок «цена ↔ качество» проекта
  сдвинут к цене (ТЗ п. 2.7). Сдвиньте к качеству или ставьте исполнителя руками.
* **Слишком длинный вход** — контекст 262 144 токена, вчетверо меньше, чем у флагманов.
* **404 «No endpoints found»** — потерян префикс вендора или сменился слаг у шлюза.
