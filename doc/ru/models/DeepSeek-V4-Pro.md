# DeepSeek-V4-Pro

**Размещение:** облако (API DeepSeek, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://api.deepseek.com`,
модель `deepseek-v4-pro`
**Ссылка на ключ:** `deepseek.apiKey`

Дешёвая модель приличного уровня: код и тексты на 84–89 из 100 по оценкам навыков
при цене примерно в двадцать раз ниже Claude-Fable-5. Хороший выбор для объёмной рутины.

## Как получить ключ

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com/).
2. Пополните баланс: **Top up** (оплата картой). Без баланса запросы отклоняются.
3. Откройте **API keys → Create new API key**, дайте имя.
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `sk-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → DeepSeek-V4-Pro → «Установить ключ API»**.

Ключ общий с DeepSeek-V4-Flash — обе модели ссылаются на
`deepseek.apiKey`. Ввели один раз — работают обе.

Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ).

к `https://api.deepseek.com`. Актуальные цены —

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.deepseek.com`.

## Частые ошибки

* **402 / «Insufficient Balance»** — не пополнен баланс.
* **Ответ пустой, причина `length`** — модель израсходовала лимит ответа на рассуждения;
  увеличьте `params.maxTokens` в профайле модели.
* **Слишком длинный вход** — миллион токенов кажется бесконечным, но история чата
  уезжает во вход при каждом ходе агента; выносите объёмные материалы в файлы, а в
  описание давайте ссылки.
