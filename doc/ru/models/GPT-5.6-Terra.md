# GPT-5.6-Terra

**Размещение:** облако (API OpenAI, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://api.openai.com/v1`,
модель `gpt-5.6-terra`
**Ссылка на ключ:** `openai.apiKey`

Средний тариф линейки: оценки навыков 85–88 против 91–95 у
GPT-5.6-Sol, а цена в пять раз ниже при том же контексте
в 1 050 000 токенов. Хороший выбор для объёмной работы, где флагман избыточен, но
качество должно оставаться высоким.

## Как получить ключ

**Ключ тот же самый**, что у GPT-5.6-Sol: обе модели ссылаются на `openai.apiKey`.
Если он уже введён — эта модель заработает сама.

Если ключа ещё нет:

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com/).
2. Пополните баланс: **Settings → Billing → Add to credit balance**.
3. Откройте [platform.openai.com/api-keys](https://platform.openai.com/api-keys) →
   **Create new secret key**.
4. Скопируйте значение (показывается один раз, начинается с `sk-`).
5. В AI2P: **Настройки → Справочники → ИИ-модели → GPT-5.6-Terra → «Установить ключ API»**.

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 050 000 токенов |
| Максимум ответа | 128 000 токенов |
| Стоимость входа | 1,00 $ за 1 млн токенов |
| Стоимость выхода | 6,00 $ за 1 млн токенов |

**Цену обязательно сверьте перед серьёзными тратами.** Источники расходятся: обзор рынка
(отчёт T-213) давал 2,50 $ и 15,00 $, публичный каталог моделей на 17.08.2026 — 1,00 $ и
6,00 $. В справочник занесены вторые числа. Актуальный прайс —
[OpenAI Pricing](https://openai.com/api/pricing/).

**Идентификатор модели живым вызовом не проверен** — он взят из каталога моделей без
префикса вендора. Перед первым заданием сверьте его запросом `GET /models` к
`https://api.openai.com/v1`.

## Лицензия

| | |
|---|---|
| Условия на результат генерации | **результат ваш**: «Customer owns all Output», OpenAI передаёт вам свои права на него |
| Коммерческое использование | разрешено |
| Что обязательно | соблюдать Usage Policies; помнить, что уникальности результата вам не обещают — тот же ответ может достаться другому |
| Текст условий | <https://openai.com/policies/services-agreement/> |
| Плата за генерацию | по токенам — тариф в разделе «Ограничения и стоимость» |

Веса закрыты, лицензировать нечего — условия относятся к **результату генерации**.

Содержимое, уходящее в API, OpenAI **не использует для развития своих сервисов**, пока вы
явно этого не разрешили; у потребительского ChatGPT это не так.

Сверено 27.08.2026: формулировка о владении результатом («you … own the Output. We hereby
assign to you all our right, title, and interest, if any, in and to Output») прочитана в
условиях OpenAI дословно; та же формулировка стоит в соглашении для API по ссылке выше.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.openai.com`.

## Частые ошибки

* **404 «model not found»** — id сменился; сверьте списком `GET /models`.
* **429 «insufficient_quota»** — не пополнен баланс организации OpenAI.
* **Счёт вышел вдвое больше расчётного** — проверьте цену по прайсу провайдера
  (см. выше) и поправьте её в декларации модели.
