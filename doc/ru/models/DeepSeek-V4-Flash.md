# DeepSeek-V4-Flash

**Размещение:** облако (API DeepSeek, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://api.deepseek.com`,
модель `deepseek-v4-flash`
**Ссылка на ключ:** `deepseek.apiKey`

Быстрая и очень дешёвая: качество ниже, чем у DeepSeek-V4-Pro
(оценки навыков 76–84 против 84–89). Берите её на простую массовую работу: переводы,
короткие сводки, черновики, мелкие правки. Самая дешёвая запись справочника теперь не
она, а Ling-3.0-Flash — 0,021 $ за миллион входных токенов.

## Как получить ключ

**Ключ тот же самый**, что у DeepSeek-V4-Pro: обе модели ссылаются на `deepseek.apiKey`.
Если он уже введён — эта модель заработает сама.

Если ключа ещё нет:

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com/).
2. Пополните баланс (**Top up**).
3. **API keys → Create new API key**, скопируйте значение (показывается один раз).
4. В AI2P: **Настройки → Справочники → ИИ-модели → DeepSeek-V4-Flash → «Установить ключ API»**.

Числа обновлены: контекст вырос со 128 000 до миллиона, максимум ответа — с 8 192 до
32 768 токенов, цена упала вдвое-вчетверо (было 0,27 $ и 1,10 $). Выход теперь **в семь
раз дешевле**, чем у DeepSeek-V4-Pro, при том же контексте.

В профайле стоит `params.maxTokens: 32768` — это потолок одного ответа у этой модели.

**Идентификатор модели живым вызовом не проверен** — сверьте его запросом `GET /models`
к `https://api.deepseek.com`. Актуальные цены —
[DeepSeek Pricing](https://api-docs.deepseek.com/quick_start/pricing).
