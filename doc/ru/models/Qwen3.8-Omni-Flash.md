# Qwen3.8-Omni-Flash

**Размещение:** облако (Alibaba DashScope, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`,
`baseUrl: https://dashscope-intl.aliyuncs.com/compatible-mode/v1`, модель `qwen3.8-omni-flash`
**Ссылка на ключ:** `qwen.apiKey`

Alibaba выпустил эту модель 21.09.2026; в справочник AI2P она занесена заданием
T-347-S0 — обходом производителей от 23.09.2026. Идентификатор `qwen/qwen3.8-omni-flash`, длина
контекста, цена и модальности сверены запросом к публичному каталогу OpenRouter.

Продолжает линейку **Qwen3.8-Max**: контекст 1 000 000 токенов, ответ до 32 768 токенов,
цена 0,15 $ и 0,47 $ за миллион токенов. Оценки навыков 82–89.

На вход принимает: текст и разметку Markdown, исходный код, изображения, звук, видео.

## Как получить ключ

1. Зарегистрируйтесь в [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/)
   (международная площадка).
2. Активируйте сервис моделей и привяжите способ оплаты.
3. Откройте **API-KEY → Create API Key**, выберите рабочее пространство.
4. Скопируйте значение — оно показывается **один раз**. Ключ начинается с `sk-`.
5. В AI2P: **Настройки → Справочники → ИИ-модели → Qwen3.8-Omni-Flash → «Установить ключ API»**.

Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ). У **локальных** моделей Qwen из справочника ключа нет вовсе —
они работают на своём компьютере.

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 000 000 токенов |
| Максимум ответа | 32 768 токенов |
| Стоимость входа | 0,15 $ за 1 млн токенов |
| Стоимость выхода | 0,47 $ за 1 млн токенов |

**Идентификатор модели живым вызовом не проверен** — он взят из каталога моделей без
префикса вендора. Сверьте его запросом `GET /models` к
`https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. Актуальные цены — в консоли
Model Studio.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к
`dashscope-intl.aliyuncs.com`.

## Частые ошибки

* **404 или «model not exist»** — либо сменился id, либо взят не тот хост
  (международный против китайского).
* **401 «InvalidApiKey»** — ключ создан в другом рабочем пространстве.
* **Ответ пустой, причина `length`** — увеличьте `params.maxTokens` в профайле
  (по умолчанию 32000).
