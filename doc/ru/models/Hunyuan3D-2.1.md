# Hunyuan3D-2.1

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: comfyui`, `baseUrl: http://127.0.0.1:8188`, модель `hunyuan3d_2_1`
**Ключ API:** не нужен — сервер поднимается локально без авторизации
**Что делает:** изображение → 3D-модель, навык `3d-image` 86

Открытая модель Tencent, превращающая ОДНУ картинку в трёхмерную сетку. Первая локальная
запись справочника, закрывающая 3D: до неё навыки `3d-*` были только у облачных Tripo и
Meshy.

Работает через **ComfyUI**: AI2P поднимает его как локальный сервер, отправляет workflow
и забирает готовый `.glb` в артефакты задачи.

**Читается КАРТИНКА, а не текст.** В графе модели нет текстового энкодера вовсе — условие
даёт CLIP Vision по стартовому кадру. Описание задачи модель не видит: что нарисовано на
картинке, то и получится. Стартовый кадр задаётся в описании задачи ссылкой на объект
проекта (`@obj:OBJ-3`) либо путём файла относительно папки проекта; без него задание не
запустится вовсе.

**Цвета не будет.** ComfyUI считает только ветку ФОРМЫ Hunyuan3D
(`VAEDecodeHunyuan3D` → `VoxelToMesh` → `SaveGLB`). Ветка окраски из репозитория Tencent —
та самая, которой нужны Linux, CUDA 12.4 и своя CUDA-растеризация, — в движке не
реализована, и подключить её штатным пакетом нельзя. Нужна цветная сетка — берите
[TRELLIS-2](https://huggingface.co/microsoft/TRELLIS.2-4B), она заведена соседней записью.

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
Модели → Hunyuan3D-2.1 → «Установить»**. Ставятся:

* **пакет ComfyUI** (~2,1 ГБ) — портативная сборка с собственным Python;
* **один файл весов** в репозиторий моделей (`storage.modelsRepo`), группа `Hunyuan3D-2.1`:

| Файл | Размер | Куда |
|---|---|---|
| `hunyuan_3d_v2.1.safetensors` | ~6,86 ГиБ | `checkpoints` |

**Итого около 7,4 ГБ загрузки.** Качается с докачкой: прерванная установка продолжится
с того места, где остановилась, уже скачанные файлы не перекачиваются.

Пока файлы не на месте, модель **не может быть активной** — это проверяется и при старте
приложения.

## Требования к железу

| | |
|---|---|
| Видеокарта | NVIDIA, **от 8 ГБ VRAM** (12 ГБ комфортно) |
| Драйвер NVIDIA | **580 или новее** — на старом драйвере torch падает без сообщения |
| Место на диске | ~10 ГБ (веса + пакет ComfyUI) |
| Оперативная память | от 16 ГБ |
| ОС | Windows (портативная сборка ComfyUI); на Linux ComfyUI ставится руками |

Цифра по видеопамяти — **оценка**, а не замер: считается только ветка формы, и требование
«10–29 ГБ VRAM», которое встречается в обзорах Hunyuan3D 2.1, относится к полному
конвейеру Tencent вместе с запеканием текстуры. Не хватило памяти — уменьшайте
`octree_resolution` в шаблоне workflow.

## Сколько ждать

Единицы минут на модель на современной карте. Таймаут задания в профайле выставлен в
60 минут (`params.timeoutMinutes`).

Ход генерации виден в **консоли задания** в карточке задачи: туда льётся собственный
вывод ComfyUI вместе с его прогресс-баром.

## Параметры генерации

Правятся в профайле модели (кнопка «Профайл подключения»):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `steps` | 30 | шагов диффузии; ниже 20 форма разваливается |
| `timeoutMinutes` | 60 | сколько ждать результат |
| `width` / `height` | 1024 | на результат НЕ влияют: у 3D нет кадра |
| `negative` | пусто | не действует — текстового энкодера в графе нет |

Плотность сетки задаётся не профайлом, а самим шаблоном workflow: `octree_resolution`
у `VAEDecodeHunyuan3D` (256) и `threshold` у `VoxelToMesh` (0.6).

## Обучение LoRA

**Не поддерживается, и это честный отказ, а не недоделка.** Публичного тренера LoRA для
3D-архитектур сегодня нет: [musubi-tuner](https://github.com/kohya-ss/musubi-tuner), на
котором держится всё обучение адаптеров в AI2P, умеет только картинки и видео. Поэтому в
профайле стоит `lora.supported: false`, и форма модели показывает причину словами.

Постоянство объекта между кадрами достигается здесь другим способом: одну и ту же
эталонную картинку персонажа (объект проекта, ссылка `@obj:`) подавайте на вход — от
одинаковой картинки и одинакового `seed` выйдет одинаковая сетка.

## Частые ошибки

* **«Модель не установлена»** — файл не докачан; откройте «Установить», окно покажет
  оставшийся объём.
* **Задание отказывается стартовать без картинки** — так и задумано: модель работает
  только от изображения. Дайте ссылку `@obj:` на эталонный кадр или путь файла.
* **Модель получилась белая** — цвета у этой записи не бывает вовсе (см. начало).
* **Нехватка VRAM** — уменьшите `octree_resolution` в шаблоне workflow.
* **Процесс исчезает без сообщения** — почти всегда старый драйвер NVIDIA (см. выше).
