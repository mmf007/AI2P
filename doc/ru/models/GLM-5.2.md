# GLM-5.2

**Размещение:** облако (Z.ai / Zhipu, OpenAI-совместимый)
**Подключение:** `provider: openai-compatible`, `baseUrl: https://api.z.ai/api/paas/v4`,
модель `glm-5.2`
**Ссылка на ключ:** `zai.apiKey`

**Лучший код среди открытых моделей после Kimi-K3** — оценка `code-write` 91
из 100, и при этом втрое дешевле: 1,19 $ и 3,74 $ за миллион токенов. Контекст
1 048 576 токенов. Ниша очевидна: объёмная работа с кодом, где Opus и GPT-5.6-Sol
обходятся слишком дорого.

Тексты даются ей хуже кода (оценки 83–86), вход — только текст и исходники, картинок
модель не принимает.

## Как получить ключ

1. Зарегистрируйтесь на [z.ai](https://z.ai/) (международная площадка Zhipu).
2. Пополните баланс в разделе биллинга — без баланса запросы отклоняются.
3. Откройте [список ключей](https://z.ai/manage-apikey/apikey-list) → **Create API key**,
   дайте имя.
4. Скопируйте значение — оно показывается **один раз**.
5. В AI2P: **Настройки → Справочники → ИИ-модели → GLM-5.2 → «Установить ключ API»**.

Ключ принадлежит организации: шифруется её ключом и реплицируется на все серверы
организации (гл. 10 ТЗ).

## Ограничения и стоимость

| | |
|---|---|
| Контекст | 1 048 576 токенов |
| Максимум ответа | 65 536 токенов |
| Стоимость входа | 1,19 $ за 1 млн токенов |
| Стоимость выхода | 3,74 $ за 1 млн токенов |

**Идентификатор модели живым вызовом не проверен** — он взят из каталога моделей без
префикса вендора. Сверьте его запросом `GET /models` к `https://api.z.ai/api/paas/v4`.

Обратите внимание на необычный `baseUrl`: путь `/api/paas/v4`, а не `/v1`. Если вы
скопировали адрес из чужой инструкции и получаете 404 на все запросы — дело, скорее
всего, в нём.

## Требования к железу

Никаких: вычисления на стороне провайдера. Нужен выход в интернет к `api.z.ai`.

## Частые ошибки

* **404 на любой запрос** — обрезан или дописан путь в `baseUrl` (нужен `/api/paas/v4`).
* **401 «invalid api key»** — ключ создан на китайской площадке (`bigmodel.cn`),
  а адрес международный.
* **Модель отказывается принять картинку** — вход только текстовый; для мультимодальных
  заданий берите MiniMax-M3 или Gemini.
