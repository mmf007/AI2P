# Kandinsky-5.0-T2V-Lite-distil16-10s

**Размещение:** ЛОКАЛЬНАЯ (работает на этом компьютере)
**Подключение:** `provider: comfyui`, `baseUrl: http://127.0.0.1:8188`, модель `kandinsky5lite_t2v_distilled16steps_10s`
**Ключ API:** не нужен — сервер поднимается локально без авторизации
**Что делает:** текст → видео, навык `video-generate` 70

Вариант открытой российской видео-модели **Kandinsky 5.0 Video Lite** (2 миллиарда
параметров) от Kandinsky Lab. Понимает промпт на русском языке и рисует **кириллицу в
кадре** — этого не умеет ни одна другая модель справочника.

Вариант **distil16**: дистиллят исходной модели, которому хватает **16 шагов** вместо
пятидесяти — вшестеро быстрее. Это самый быстрый способ увидеть черновой ролик; за
скорость платят детализацией.

Длина ролика — **10 секунд** (241 кадров при 24 кадрах в секунду): длина
зашита в самих весах, поэтому у линейки отдельные файлы на 5 и на 10 секунд.

Работает через **ComfyUI**: AI2P поднимает его как локальный сервер, отправляет workflow
и забирает готовый `.mp4` в артефакты задачи.

## Ключ не нужен, нужна установка

Всё ставится кнопкой **«Установить»** в форме модели: **Настройки → Справочники →
Модели → Kandinsky-5.0-T2V-Lite-distil16-10s → «Установить»**. Ставятся:

* **пакет ComfyUI** (~2,1 ГБ) — портативная сборка с собственным Python;
* **четыре файла весов** в репозиторий моделей (`storage.modelsRepo`), группа
  `Kandinsky-5`:

| Файл | Размер | Куда |
|---|---|---|
| `kandinsky5lite_t2v_distilled16steps_10s.safetensors` | ~4,3 ГиБ | `diffusion_models` |
| `qwen_2.5_vl_7b_fp8_scaled.safetensors` | ~8,7 ГиБ | `text_encoders` |
| `clip_l.safetensors` | ~235 МиБ | `text_encoders` |
| `hunyuan_video_vae_bf16.safetensors` | ~470 МиБ | `vae` |

**Итого около 14,6 ГБ загрузки** — самая лёгкая из видео-моделей справочника. Группа
`Kandinsky-5` общая у всей линейки: если рядом стоит другой её вариант, докачается только
свой файл весов (~4,6 ГБ), энкодеры и VAE уже на месте.

Пока файлы не на месте, модель **не может быть активной** — это проверяется и при старте
приложения.

| | |

| Драйвер NVIDIA | **580 или новее** — на старом драйвере torch падает без сообщения |

| Оперативная память | от 16 ГБ |

## Сколько ждать

Шестнадцать шагов вместо пятидесяти: ролик считается **в разы быстрее** остальных
вариантов линейки — единицы минут на современной карте против десятков.

Таймаут задания в профайле выставлен в 180 минут (`params.timeoutMinutes`). Ход генерации
виден в **консоли задания** в карточке задачи: туда льётся собственный вывод ComfyUI
вместе с его прогресс-баром.

## Параметры генерации

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `width` / `height` | 768 × 512 | разрешение кадра |
| `length` | 241 | кадров в ролике; 24 кадра в секунду, то есть 10 с |
| `steps` | 16 | шагов диффузии — столько же, сколько у обучающей задачи этого варианта |
| `negative` | пусто | негативный промпт — **у этого варианта не действует**: он обучен считать без второго прохода |
| `timeoutMinutes` | 180 | сколько ждать результат |

Описание задачи целиком уходит в промпт. Указание вида «результат положить в файл X.mp4»
исполняется коннектором: файл копируется в папку проекта, а сама строка из промпта
вырезается.

## Обучение LoRA

Поддержано полностью: адаптер и **применяется** (узел `LoraLoaderModelOnly` вставляется
в граф на лету), и **обучается** прямо из AI2P — редактором LoRA в карточке объекта
проекта.

Обучает [musubi-tuner](https://github.com/kohya-ss/musubi-tuner) — скрипты
`kandinsky5_cache_latents.py`, `kandinsky5_cache_text_encoder_outputs.py` и
`kandinsky5_train_network.py` (`--task k5-lite-t2v-10s-distil-sd`,
`--network_module networks.lora_kandinsky`), одна видеокарта, внимание через `sdpa`.
Задача тренера у каждого варианта своя — она задаёт и число шагов, и расписание, поэтому
подставлять чужую нельзя.

Пакет `musubi-tuner` (исходники, ~30 МБ) и **Python 3.12** (~45 МБ) ставятся вместе с
моделью; окружение с `torch` (~3 ГБ) тренер создаёт себе при первом запуске обучения.
Догружать веса, в отличие от Wan 2.2 и HunyuanVideo 1.5, не нужно: файл DiT и так не
fp8, а свои текстовые энкодеры тренер берёт сам с HuggingFace.

Готовый адаптер ложится в `<репозиторий моделей>/loras/<код объекта>.safetensors`. Все
ключи обучения, `dataset.toml` и `train.cmd` лежат в профайле модели (`lora.train`) и
переписываются перед каждым запуском — правьте их в профайле, а не в файлах.

## Частые ошибки

* **Процесс исчезает без сообщения** — почти всегда старый драйвер NVIDIA (см. выше).
* **«Модель не установлена»** — файлы не докачаны; откройте «Установить», окно покажет
  оставшийся объём.
* **Нехватка VRAM** — уменьшите `width`/`height`; ролик на 241 кадров держит в памяти
  весь латент целиком.
* **ComfyUI занят чужим процессом** — AI2P выгружает только тот сервер, который запустил
  сам; уже работающий чужой ComfyUI на 8188 он не трогает.
