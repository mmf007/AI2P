# Contributing to AI2P

Thank you for your interest in AI2P. How to build it, run the tests, report bugs and send
changes is described in the developer guide, available in five languages:

* [English](doc/en/man/build.md)
* [Русский](doc/ru/man/build.md)
* [Español](doc/es/man/build.md)
* [Português](doc/pt/man/build.md)
* [中文](doc/zh-cn/man/build.md)

In short:

* **Build:** .NET 8 SDK; `build.cmd` / `./build.sh` for development, `buildRelease.cmd` / `./buildRelease.sh` for a release layout.
* **Tests:** `dotnet test` in the repository root.
* **Bugs** — via the issue form; **questions** — in [Discussions](https://github.com/mmf007/AI2P/discussions).
* **Pull requests** are accepted after agreement in an issue.
* **License:** Apache-2.0 — code you contribute is licensed under it.
* **Vulnerabilities** — never in a public issue, see [SECURITY.md](SECURITY.md).
